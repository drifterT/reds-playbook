---

## 1. プロジェクトの目的

reds-playbook は、コーチ陣と保護者が同じ画面を見て、レギュラー練習の進め方・内容・ねらいと、その根拠となる指導コンテンツを共有するためのサイト。

- 主目的は **コーチ陣の認識あわせ**。
- 閲覧の中心はコーチ陣。画面はコーチ陣・保護者で共通。
- モバイル前提。

---

## 2. サイト第一階層

第一階層は3セクション。性質で「不変／可変／正解」に分かれる。

```
reds-playbook  ── 目的：コーチ陣の認識あわせ
│
├─ レギュラー練習メニュー   【常設・標準】
│   ├─ 練習の流れ
│   ├─ アップ
│   ├─ 2箇所キャッチボール ①②③
│   ├─ 4箇所キャッチボール ①②
│   └─ バッティング練習（心得＋パターン①②③）
│
├─ 方針・心得               【不変・チーム運営の決めごと】
│   ├─ コーチ心得
│   ├─ 選手心得
│   └─ コーチ配置（要再検討あり）
│
└─ Playbook                 【正解・指導の教本】
     ├─ Text編              ← Ameblo由来の本文／11カテゴリ
     └─ ケース編            ← 状況判断の図解（既存HTML）
```

- **Playbook Text** は「アーカイブ」ではなく指導の正解（教本）。各メニューのねらいから該当章へリンクする。
- **11カテゴリ**：バッティング／ピッチング／守備／走塁／ルール／メンタル・姿勢／道具／身体構造・ストレッチ／指導方法／基礎運動能力／戦術・戦略。Playbook Text の章立てであり、メニュー・ねらいにも付与する横断タグ。
- 「ねらい」は週次の見出しではなく、各メニューが持つ狙い。ねらい → 方針・心得／Playbook Text へのリンクが認識あわせの動線。

## 3. レギュラー練習メニューの構造

ブロック層とカード層の2層。練習メニューは週単位で切り替わらない常設メニュー。不変／可変はカード単位のタグ。

### ブロックの項目

- ブロック名
- ブロックの狙い
- ブロック共通心得（任意：バッティング練習心得など）
- 進行ルール（時間調整・グループ分け・人数不足時の判断）
- ドリルカード（順序つき）

### ドリルカード スキーマ（アップ／2箇所／4箇所）

- 名称
- 不変／可変タグ
- ステータス（確定／要確認）
- ねらい（狙い）※役割別に分割可：投球者／捕球者／打者
- やり方（手順）
- 設定：人数・構成／距離／量（回数・セット・時間）
- 競争・ルール（任意）
- コーチの見るポイント
- → Playbook Text リンク（根拠の章）
- イメージ案（添えるイメージアニメーション）

### バッティング構成カード スキーマ（バッティング）

守備と違い教える観点が複雑なため、ねらいは持たせず、練習方法・コーチ配置・場所の可視化に絞る。

- 名称（パターン①／②／③）
- 不変／可変タグ
- ステータス（確定／要確認）
- 想定人数（このパターンを選ぶ目安）
- 練習方法（グループ分け・ローテーション・巡数）
- コーチ配置（大人の人数と各自の役割）
- 場所（フィールド構成：使うエリアと各エリアの内容）
- → Playbook Text「バッティング」章へのリンク（教える観点の詳細はここに委ねる）

アップ-10 ラスト10
  不変／可変：不変    ステータス：確定

  やり方 ：捕ったらすぐに相手へ返球。連続10回
