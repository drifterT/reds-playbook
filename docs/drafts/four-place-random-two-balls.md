## 4箇所-02 ランダム・ボール2個

### 位置づけ

- 4箇所キャッチボールの発展形。
- 単なる送球練習ではなく、周囲確認、声かけ、判断、安全停止を含める練習。
- 練習効果よりも、安全に止められることを優先する。

### ねらい

- 複数のボールが動く状況で、周囲を見てから投げる。
- 次の送球先を声で共有する。
- 危ない場面では無理に続けず止める。

### やり方案

- 4箇所に選手を配置する。
- ボール2個で開始する。
- 最初は投げる順番を限定する。
- 慣れてからランダム要素を入れる。
- 投げる前に送球先を声で伝える。
- 危ないと感じたら「ストップ」で全員停止する。

### 設定案

- ボール: 2個
- 配置: ホーム / 1塁 / 2塁 / 3塁 を想定
- 送球が飛んできた方向への返球は禁止する。
- 例: 1塁で2塁からの送球を受けた場合、次に送球できるのは3塁またはホーム。
- 開始位置: 要確認
- 投げてよい塁: 要確認
- 人数: 要確認
- 距離: グラウンド条件・学年で調整
- 実施時間 / 回数: 要確認

### 見るポイント

- 投げる前に送球先を見ているか。
- 声で送球先を共有しているか。
- 捕球後に慌てて投げていないか。
- ボール2個の位置を把握しようとしているか。
- 危ない場面で止める判断ができているか。
- 待つ側が構えと声を切らしていないか。

### 安全停止条件

以下の場合は、成功数やテンポよりも停止を優先する。

- ボール同士の進行方向が交差しそうな時。
- 選手が送球先を見ずに投げようとした時。
- 捕球側が準備できていない時。
- 声が出なくなった時。
- ランナーや他メニューの選手が送球線上に入った時。
- コーチが危ないと判断した時。

### 禁止事項

- 送球先を見ずに投げる。
- 声なしで投げる。
- 捕球側が構えていないのに投げる。
- スピード競争にする。
- 危ない場面で無理に続ける。

### 段階的な進め方

1. 固定順・ボール1個
2. 固定順・ボール2個
3. 指定順・ボール2個
4. 限定ランダム・ボール2個
5. 完全ランダムに近い形

完全ランダムに近い形は、安全条件が満たせる場合のみ実施する。声が出ない、送球先確認ができない、周囲確認が崩れる場合は前の段階に戻す。
