# 8枚スライド案：骨格レビューへの回答

対象：`docs/drafts/codex/batting-foundation-slides-draft.md`

## 結論

「2つの主動作＋着地の結合部」という整理は採用する。「単離→負荷→結合」は、誤解を避けるため **「単離→制約付き反復→結合」** と言い換える。

ただし、次の2点は補正が必要。

1. **トップと割れは同じものではない。** トップは引き手の腕・バットを含むスイング開始前の準備姿勢、割れは下半身と上半身が逆向きに進もうとする関係である。着地局面で同時に整うため、1枚で扱うのは妥当だが、等号では結ばない（原典 p120–121、p135–139、p154–157）。
2. **「動作2がまだ始まっていない」も限定が必要。** テイクバック中にも上体は準備動作をしている。着地まで始めないのは、バットを引き出すための速い上体回転である（原典 p137–138）。

この補正に加え、左右対称スイングを本編から外し、ワンレッグとウォークスルーを追加した第3版を `batting-foundation-slides-draft.md` に反映した。

## 1. 「2動作＋結合部」への回答

### 採用する整理

- **動作1**：踏み出し、後ろ腰の直進、踏み出し脚側への支点移動、骨盤の回転
- **動作2**：背骨付近を軸にした胸郭の回転、引き手の肩による始動、球に合うバットの面
- **結合部**：踏み出し足の着地局面。トップと割れが整い、動作1と動作2が重なってつながる

原典 p066 は、着地時に骨盤のスライドから始まる回転と、両肩を入れ替える上体回転を同時に行うとしている。p137–138 は、着地寸前までにテイクバックを終え、完全着地を合図に割れを戻して上体回転のリードを始めるとしている。したがって、4項目を別々の技術として並べるより、2動作と結合部で見せる方が原典の関係を伝えやすい。

### 原典に無い部分

「2動作＋結合部」という分類名自体は原典に無い。原典の複数章をチーム向けに再配置した編集上の整理である。資料では、その旨を明記する。

## 2. 「単離→制約付き反復→結合」への回答

骨格として有効。ただし、原典がこの名称で体系化しているわけではない。

| 段階 | 候補で行うこと | 判定 |
|---|---|---|
| 動作2の単離：p054–057 | 骨盤と顔を正面に保ち、上体回転を取り出す | 妥当 |
| 動作1の単離：p122–127 | 支えを使い、骨盤の横移動と回転を二つに分ける | 妥当 |
| 動作1の制約付き反復：p120–121 | 台によって踏み出し脚側で支えやすい条件を作る | 妥当 |
| 動作1の制約付き反復：ワンレッグ | 一歩の後に後ろ足を後方へ上げ、踏み出し脚側で姿勢と回転を受ける | 外部候補として採用 |
| 動作1の動的な結合：ウォークスルー | 歩く勢いとリズムを加え、前進から着地・回転へつなぐ | 外部候補として採用 |
| 結合：p066–069、p135–139、p154–161 | ステップ、着地、テイクバック、上体回転を組み合わせる | 妥当 |

「負荷」は、重さや身体負担を増やす意味に読める。BOXスイングは負荷を増やすより、目的の動きを出しやすくする制約であるため使わない。「もう一方を殺す」も原典の表現ではなく、動きを完全に消す印象が強いので、**「制約で焦点を一つに絞る」** とする。

この段階は日・週単位の進級ではない。**同じ練習内で、崩れたら制約を一つ戻し、安定したら一つ外す**ための判断軸として使う。

## 3. 8枚の配分

提案された配分を基本採用した。第3版は次の構成。

1. 2つの動作と結合部
2. 動作2の単離：上体回旋（肩甲骨ストレッチは導入に縮小）
3. 動作1の単離：椅子
4. 動作1の制約付き反復：BOXスイング
5. 動作1の制約付き反復から動的な結合へ：ワンレッグ→ウォークスルー
6. 結合1：p066–069で腰の前進・回転と胸郭回転を重ねる
7. 結合2：トップと割れ＋置きティー
8. コーチの観察、制約の上げ下げ、中止判断

p054–057の格上げには賛成する。これは準備運動ではなく、上体回転を取り出す中心ドリルである。p172–175の肩甲骨ストレッチだけをSlide 2の導入に置いた。

チーム独自の片手ティーは、構成要素を教える前に置かない。Slide 7の最後に、**すべての構成要素を経験した後の試行候補**として小さく置いた。

### ワンレッグとウォークスルーの位置づけ

- ワンレッグは、通常の一歩の後に後ろ足を後方へ上げることで、踏み出し脚側で姿勢と回転を受ける制約。後ろ足を前へ回して勢いを作らない。
- ウォークスルーは、その場の一歩より前進量とリズムが大きい発展形。Driveline型は投手正面から軸足→踏み出し足の順に進む。
- Baseball Utility型は通常に近い横向きから軸足を交差させ、踏み出し足をボックス内へ運ぶ。開始姿勢と足運びが異なるため、2動画の手順を一つの「原型」として混ぜない。第3版はDriveline型を本文の基本形とした。
- 「前脚を固める」「直進エネルギーが強制的に回転へ変わる」は、少年への実施指示にしない。見るのは、前足の安定、頭の流れ、後ろ残り、歩調の乱れである。
- これらは動作1の学習を厚くするドリルであり、左右対称スイングが担っていた引き手の肩とバット面の学習を直接代替しない。動作2はSlide 2・6・7・8に残す。

### 外部呼称と根拠の再確認

追加情報のうち、**踏み出し脚側の支持が打撃の力学上重要**という方向性は採用できる。ただし、次の範囲を越えては書かない。

- `Front Leg Post Drill` は、後ろ足を浮かせて踏み出し脚で終える型の公開指導例として確認できる。`Flamingo Drill` を同義に使う指導例もある。
- 一方、U.S. Baseball Academyなどの `Flamingo Drill` は、最初に前脚を上げ、後ろ脚へロードしてから踏み出す別動作である。名称だけでJBS武蔵のワンレッグと同一視しない。
- `Single-Leg Finish Drill` と `Post-Impact Balance Drill` が野球界で標準化された名称であること、Drivelineが同型を一般ドリルとして公開していることは、今回確認できなかった。
- 大学生20名のティー打撃研究では、踏み出し足の最大地面反力とバット速度に相関があった。しかし、ワンレッグの効果を比較した研究ではなく、対象も10〜12歳ではない。
- ユースと成人では踏み出し脚の屈曲・伸展量や体幹速度が異なる。したがって、一本脚で立てることを合格条件には使えても、前膝のロックや成人並みの制動量を目標にしない。

以上から、資料上の位置づけは **「踏み出し脚側で姿勢を保てるかを誇張して確認する制約ドリル」** とする。「万能」「完全に一致」「英語文献で強く推奨」「エネルギーの逃げを強制的になくす」は採用しない。

- YouGoProBaseball, Front Leg Post Drill: https://www.youtube.com/watch?v=noz-aYI7pXg
- Orishimo et al. (2024), Sports Biomechanics: https://pubmed.ncbi.nlm.nih.gov/37853750/

## 4. p135–139の配分

独立した4本目の技術として1枚を与えない。一方、単なる脚注にも落とさない。

**Slide 7で、結合部を下半身側から作る制約として扱う。** p154–161が踏み出しとグリップの関係を上半身側から作り、p135–139が膝と上体の反対向きの関係を下半身側から作る、という配置にする。

ただし原典 p135は、特に踏み出し脚の膝が内へ向く選手のためのドリルとして紹介している。この対象限定は消さない。全員に行わせる場合は、**原典の汎用指定ではなくチームによる適用範囲の拡張**と明記する。

## 5. 欠落8点への対応

### 原典と食い違っている

1. **Slide 1の時間順序**：旧版は「前足側で受ける→後ろ腰を運ぶ」と順番に読めた。原典 p066は着地時に動きが重なる。第2版では本文と図の指示を同時性に統一した。
2. **Slide 7の「小さく下げる」**：原典 p155のSTEP1は約45度まで下げる。第2版では約45度に戻した。幅を変える説明はp166–167にあるが、最初の手順を曖昧にしない。

### 原典に無い

1. **チーム独自の片手ティー**：バットを肩に乗せる、引き手だけで持つ、一歩から打つという個々の要素は原典にあるが、この組み合わせは無い。Slide 7に「試行候補／原典に同じ組み合わせなし」と明記した。
2. **「単離→制約付き反復→結合」**：編集上の整理であり、原典の分類ではない。冒頭で明記した。
3. **地面反力によるエネルギー変換**：原典の説明ではない。8枚の本文から外し、コーチ向け背景に限定する。
4. **ワンレッグ／ウォークスルー**：いずれも外部動画由来で、原典には無い。Slide 5で出典とチーム向けの簡略化を明記した。

### この記述では教えられなかった

1. **トップづくりのSTEP2**：グリップを下げながら軸足に乗り、踏み出しで戻す、と明記した（原典 p156）。
2. **トップづくりの合格条件とSTEP4**：着地時に引き手の腕とバットを球の面へそろえること、高さを変えて素振り・ティーを行うことを追加した（原典 p157–161）。
3. **椅子ドリル**：本文を椅子に統一し、左右反復と「横移動なしで回すと逆回り」を追加した（原典 p122–125）。
4. **上体回旋の悪い形**：5項目を本文へ詰め込まず、イラスト指示にすべて残した。重点は、膝が動いて骨盤まで回る形（原典 p054–057）。
5. **BOXスイングの台**：高い台から低い台、最後に外すという原典の進め方を追加した。ただし10〜12歳では、安定して立てる高さを安全条件として先に置いた（原典 p120–121）。
6. **Slide 1とSlide 6の同時性**：両方に同じ時間帯の色帯を入れる作図指示へ統一した（原典 p066）。

左右対称スイングについて以前行った手順・合格条件の修正は、原典解釈の記録としては有効だが、第3版の8枚には採用しない。

### 追加した3点

- 「小さく前ならえ」はSlide 8の3点目に採用。ただし押し手の肘を自分で入れさせず、引き手の肩があごの下へ入り、上体が回った結果として内側へ入る順序を併記した（原典 p181–184）。
- 軸足の返りを、骨盤の動きを外から見る目印としてSlide 8に採用した（原典 p124–125）。
- 禁句「後ろに乗れ／腰を先に切れ／前脚で壁を作れ」をSlide 8に採用した（原典 p123–125、p132–135）。

## 6. イラストの要否

判断は変わらない。むしろ「単離→制約付き反復→結合」を見せるため、**Slide 2–7の全動作に図が必要**になった。

| スライド | 必要な図 |
|---|---|
| 2：p054–057 | 骨盤・顔を正面に保つ条件と、原典の悪い形5点 |
| 3：p122–127 | 腰の直線移動と、その後の回転を別の矢印で示す図 |
| 4：p120–121 | 台、踏み出し脚側の支持、台を下げて外す進行 |
| 5：ワンレッグ／ウォークスルー | 後ろ足を後方へ上げる方向、踏み出し脚側の支持、2歩の足跡と前進方向 |
| 6：p066–069 | 着地・腰の前進・骨盤回転・肩の入れ替えが重なる時間帯 |
| 7：p154–161、p135–139 | グリップと踏み出しの同期、着地時の合格線、上下の反対向き |

特にp066、p154、p135と、外部動画を基にするSlide 5は、姿勢だけでは方向と時間関係が伝わらない。矢印、面、足跡、同時性の色帯を加えた専用図が必須。p120とp122も、台や椅子が写っているだけでは目的の腰の動きが分からないため、図を省略しない。

## 要判断

### p135–139を全員に行わせるか

本資料での推奨は、結合部を理解するドリル群には残しつつ、原典どおり「特に膝が内へ入る選手」を主対象として表示すること。全員が行う場合は、チームが適用範囲を広げたと明記する。

### BOXの台の高さ

原典は高い台から順に下げる。チームで使用する具体的な高さは、選手が安定して立てることを優先して決める。原典の例示値を、全選手への固定値にはしない。
