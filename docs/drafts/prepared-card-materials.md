# 準備中カード材料メモ

この文書は、`regular-practice-menu.html` の準備中カードを将来埋めるための材料棚です。公開HTMLにはまだ反映しない。

カード項目は今後、次の用語で統一する。

- ねらい
- やり方
- 設定
- 見るポイント
- 要確認

「見るポイント」は、この練習の時にコーチや選手が注意することを平易に示す項目とする。

## 参照材料

- `data/ameblo/manual_articles/catchball-material-001.md`

今回追加した材料は `manual_note` であり、Ameblo記事本文の長文転載ではない。Ameblo URLがある材料は現時点では含まない。

## 2箇所-01 チーム対抗・1分間成功数

### 現状

- 準備中

### 使える材料

- `data/ameblo/manual_articles/catchball-material-001.md`
- `article_index.json`: `manual:catchball-material-001`
- target section: `practice_two_point_catchball`

### 仮のねらい

- 捕ってから返すまでのテンポを上げる。
- チーム内で集中して連続成功を目指す。

### 仮のやり方

- チームごとに分かれて、1分間で何回成功できるかを数える。
- 暴投や捕球ミスが出た場合の扱いは事前に決める。

### 仮の設定

- 時間: 1分
- 人数: 要確認
- 距離: 要確認

### 仮の見るポイント

- 捕球後に止まらず、次の送球準備に入れているか。
- 速さを求めすぎて送球や捕球が雑になっていないか。
- 声かけが次の行動につながっているか。

### 要確認

- 成功数のカウントルール。
- ミス時にゼロから数え直すか、累計にするか。

## 2箇所-02 全員で1分35回チャレンジ＋個別指導

### 現状

- 準備中

### 使える材料

- `data/ameblo/manual_articles/catchball-material-001.md`
- `article_index.json`: `manual:catchball-material-001`
- target section: `practice_two_point_catchball`

### 仮のねらい

- 全体のテンポをそろえながら、必要な選手には短く個別指導を入れる。

### 仮のやり方

- 全員で1分35回を目標にする。
- 個別指導担当は、全体の流れを止めすぎずに1点だけ伝える。

### 仮の設定

- 時間: 1分
- 目標: 35回
- 担当: 全体進行と個別指導の分担は要確認

### 仮の見るポイント

- 捕球から返球までのリズムが崩れていないか。
- 個別指導が長くなりすぎていないか。
- 選手が目標回数だけでなく送球の質も意識できているか。

### 要確認

- 35回の基準を学年や人数で変えるか。
- 個別指導対象の選び方。

### 要確認
