## 7. 用語の確認事項

- **「割れ」の定義は第4章 p084 で決着した。** 本書自身が「ボトムハンドの肩にストレッチ状態をつくること（いわゆる「割れ」）」と書いている。つまり **割れ＝ボトムハンド側の肩のストレッチ状態**。
- これと第2章の**「捻れ」＝骨盤と上体の間のズレ**（p028, p038）は対の関係。**骨盤の向きを保ったまま、ボトムハンド側の肩だけを引き寄せる**ことで、捻れができ、同時に肩にストレッチがかかる。
- 量の指定は第2章のまま: **「上体は深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらいの方が効果的」（p038）**。世間で言う「割れ」より控えめ。チームで「割れ」を使うなら、この量の指定を必ず添える。
- 読み取り精度に若干の不安があるため、**第7章（テイクバック）で再確認する**。

## 8. 流れの各枠に何を入れるか（暫定）

| 枠 | 入れるもの | 根拠 |
|---|---|---|
| ストレッチ | 一般的な柔軟ではなく、**第3章の膝立ち上体回旋の可動域チェック（K-22）＋動きづくりの体操**。その日のドリルの前提を測り、選手に現状を自覚させる枠（K-24） | 書籍 p052-057 |
| ドリル | 第2章 STEP1〜6、第3章 STEP1〜3。片手→両手の順（K-09）。意図的なオーバーコレクションを含む（K-31） | 書籍 p022-063 |
| 置きT | 動作を切り出して固める枠。球の変動を排して動作に集中できる | 書籍（第4章 STEP6 ティー打撃 p085、STEP8 ティー打撃 p106）／Web §2-5 |
| フロントトス | 転移の枠。**必ず入れる**。ティーとフロントトスでは体幹の動きが有意に異なり、競技場面に近い形態を欠かすと転移しない | Web §2-5（Bordelon 2024, 学童20名） |

> **流れ自体が、書籍の習得順序（K-09 片手→両手→実打）と Web文献の練習形態研究の両方に素直に乗っている。** 構成を変える必要はなく、各枠の中身と判定基準を詰める作業になる。

## 9.「未成熟な年齢のため気をつけるべきこと」の材料（暫定）

- **発達のタイミング**: スイング速度・打球速度の発達は12〜13歳頃から減速する（筒井ら 2023, 6〜14歳235名）。**10〜12歳はまだ伸びる区間**なので、形の微修正でこの時期を使い切らない
- **障害リスク**: 打撃は非対称・反復で腰椎に回旋と伸展の負荷。高練習量＋回復不足＋急成長期が overuse のリスク。**打撃側には投球数制限に相当する公式ガイドラインが存在しない**（Web §2-8）
- **用具**: スイング速度はバット重量より**慣性モーメント（MOI）**に依存し、学童では成人よりその依存が強い（Web §2-6）。「重い/軽い」ではなく「振れるか」で選ぶ
- **書籍側**: 片手スイング用のバットは軽いもので構わない、段階的に重さを上げる（K-20）。脚の動きと手首の返しばかりのスイングは低学年に多い（K-19）
- **教示の言葉**: 外的焦点が学習を促進するが、基本動作を未獲得の初心者には内的教示が効く場合がある（Web §2-7）。**10〜12歳はこの境目**なので、ドリル中は身体部位の指示、置きT・フロントトスでは打球や目標への外的キュー、という使い分けが候補

## 11. 流れの妥当性について（第4章 p085 で確認）

**要件の「ドリル → 置きT → フロントトス」は、本書の段階構成とそのまま一致している。**

| 要件の枠 | 本書の対応 |
|---|---|
| ドリル | 左右対称スイング STEP1〜5（片手真下 → 両手真下 → 両手ベルト高 → 踏み出し → 横向き） |
| 置きT | **STEP6 ティー打撃**（p085） |
| フロントトス | 「足でリズムを合わせる動きを加え、個々の構え方から、実際のバッティング練習に移っていく」（p085） |

**流れを設計し直す必要はない。** ただし本書は置きTに条件をつけている——**はじめのうちは「つくったスイングがそのまま出せる位置」にティーアップする**（打ちごろの位置ではない）。この条件は要件の「指導のポイント」に必ず入れる。

## 12. 選択の原則（オーナー指示・2026-09-09）

> **全部のドリルをくまなく、漏れなく実施するわけではない。**

したがって成果物は**ドリルのカタログではなく、選抜されたメニュー**とする。第4章だけでもドリルは20種近くあり、全部やる時間はない。

**選抜の基準**

1. **4つの動作 のどれに効くか**が言えるものだけを採る。「本に載っていたから」は理由にならない
2. **10〜12歳で成立するか**（筋力・可動性・集中の持続・道具）
3. **エラーが目で見えるか**——コーチが打席横で判定できないドリルは、人数の多い学童練習では機能しない
4. **枠の役割と一致するか**（ストレッチ／ドリル／置きT／フロントトス）
5. **本書自身の位置づけを守る**——例: 障害物スイングは「確認用」であって習得用ではない（K-71）。順番を守れないなら入れない

**採らないものの扱い**: 落としたドリルも「なぜ落としたか」を1行残す。人数・時間・段階が変わったときに戻せるようにするため。
