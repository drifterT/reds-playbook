# バッティング練習3パターン ドラフト

この文書は、`regular-practice-menu.html` の打撃-01 / 02 / 03 を将来公開反映するための準備メモです。公開HTMLにはまだ反映しない。

バッティング技術の細部ではなく、練習運営カードとして整理する。カード項目は `ねらい`、`やり方`、`設定`、`見るポイント`、`要確認` で統一する。

## 共通方針

- 人数、大人の人数、場所、安全管理を先に確認してからパターンを選ぶ。
- 打撃量を増やすことと、安全管理を薄くしないことを両立する。
- 待機選手がただ待つだけにならないように、待機場所と役割を決める。
- 技術指導は多く言いすぎず、その日のねらいに絞る。
- 打球方向、立入禁止エリア、球拾い導線は必ず確認する。

## 打撃-01 パターン① 21名想定・メイン＋ケージ併用

### ねらい

- 人数が多い日の標準型として、打撃量を確保しながら安全にローテーションする。
- メイン打撃とケージを併用し、待ち時間を減らす。

### やり方

- メイン打撃とケージを並行して行う。
- 選手を打席、待機、守備または補助に分ける。
- ローテーション順を決め、移動のタイミングをコーチが管理する。
- ケージ側にも担当を置き、打つ側だけでなく待つ側も見る。

### 設定

- 想定人数: 21名
- 場所: メイン打撃エリア、ケージ、待機場所を分ける。
- ローテーション: 要確認
- 大人の必要人数: 要確認

### 見るポイント

- 待ち時間が長くなりすぎていないか。
- 打席周辺の安全確認ができているか。
- メイン側とケージ側の両方に大人の目が届いているか。
- 選手の移動が打球方向や送球線と交差していないか。

### 安全管理

- 打球方向と立入禁止エリアを事前に決める。
- ケージ側の担当を曖昧にしない。
- 待機場所を打球が飛ぶ場所から外す。
- 球拾いは合図があるまで入らない。

### 要確認

- 配置図。
- ローテーション順。
- 大人の必要人数。
- ケージ側の担当。
- 打球方向と立入禁止エリア。

## 打撃-02 パターン② 20名想定・打撃と別メニュー半々

### ねらい

- 打撃待ちを減らし、半分の選手は別メニューで練習量を確保する。
- 別メニュー側を単なる待機にしない。

### やり方

- 打撃グループと別メニューグループに分ける。
- 一定時間または巡数で交代する。
- 別メニュー側にも担当コーチを置く。
- 交代時の移動導線を決めておく。

### 設定

- 想定人数: 20名
- グループ: 打撃側と別メニュー側に分ける。
- 交代条件: 要確認
- 別メニュー内容: 要確認

### 見るポイント

- 打撃側と別メニュー側の両方にコーチの目が届いているか。
- 交代が分かりやすく、移動で時間を失っていないか。
- 別メニュー側が待機時間になっていないか。
- 移動中の選手が打球方向に入っていないか。

### 安全管理

- グループ交代の合図を決める。
- 移動導線を打球方向から外す。
- 別メニュー側の担当を決め、安全確認を任せる。
- 打撃中に別メニュー側が打球エリアへ入らないようにする。

### 要確認

- 別メニュー内容。
- 交代条件。
- 別メニュー側のコーチ担当。
- 移動導線。
- 安全管理担当。

## 打撃-03 パターン③ 球数重視・大人6名

### ねらい

- 大人6名を確保できる日に、球数を増やして打撃経験を確保する。
- 球数を増やしても、安全管理を薄くしない。

### やり方

- 大人6名の役割を分ける。
- 打席補助、トスまたはマシン、安全管理、球拾い、待機選手管理を分担する。
- 技術指導はその日のねらいに絞る。
- 球拾いと待機選手の動きを止めないようにする。

### 設定

- 大人: 6名
- 球数: 要確認
- 打席数: 要確認
- 待機場所: 要確認
- 球拾い配置: 要確認

### 見るポイント

- 球数を増やしても安全管理が薄くなっていないか。
- 大人の役割が重なりすぎていないか。
- 技術指導が多すぎず、その日のねらいに絞れているか。
- 球拾いと待機選手の動きが止まっていないか。

### 安全管理

- 安全担当を必ず決める。
- 球拾いに入るタイミングを合図で統一する。
- 待機場所を打球方向から外す。
- 打席補助と安全管理を同じ人に寄せすぎない。

### 要確認

- 具体的な球数。
- 打席数。
- 大人6名の役割表。
- 球拾い配置。
- 安全担当。
- 待機場所。
