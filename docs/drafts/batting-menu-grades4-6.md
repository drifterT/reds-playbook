# バッティング指導メニュー（小4〜小6）

## 1. 習得する4つの動作

| | 動作 | 中身 | 主に鍛える枠 |
|---|---|---|---|
| **1** | **体重移動** | 軸脚が骨盤を前へ押し進める。上体だけを後ろに残したまま踏み出し脚へ乗る | ドリル・置きT |
| **2** | **ボトムハンドの肩のリードによるスイング始動とスイングプレーン** | 肩→腕→バットのラインを、球に向かうプレーンの角度に合わせ、ボトムハンドの肩からスイングを始める | ドリル・置きT・フロントトス |
| **3** | **トップの作り方** | 高めの球に対するトップを基準に、ステップに合わせてグリップを引く | ドリル |
| **4** | **割れの作り方** | 骨盤の向きを保ったまま、ボトムハンド側の肩にストレッチをかける | ドリル |

**4つとも毎回やる。** ローテーションはしない。各動作の中で段階を上げていく（各項に記載）。

---

## 2. 1回の練習

| 順 | 枠 | 時間 | 内容 |
|---|---|---|---|
| 1 | ストレッチ | 5分 | 膝立ちの上体回旋／肩甲骨の体操 |
| 2 | ドリル | 15分 | 上体の角度 → 左右対称スイング → トップのつくり方 → 割れをつくるステップ |
| 3 | 置きT | 10分 | BOXスイングでティー → 高めのティー |
| 4 | フロントトス | 15分 | その日つくった動きが球の動く条件で出るか |

45分想定。練習枠に合わせて各枠を比例で縮める。**削るときはフロントトスを残す**（ティーだけでは実戦に転移しないため。書籍・文献とも同じ立場）。

## 3. ストレッチ（5分）

一般的な柔軟ではない。**その日の可動性を測り、選手に自分の状態を自覚させる枠**。2つとも、できないこと自体が診断になる。

### 膝立ちの上体回旋

**やり方**
膝立ちになり、骨盤と顔を正面に向けたまま、上体だけを水平に回旋させる。ゆっくり最大可動域まで。左右交互に各5回×2セット。そのあと同じことを立位でも行う。

**指導のポイント**
- 声かけは「腰は動かさない。胸から上だけ回す」
- 膝立ちで行う理由を選手に言う。「立つと腰でごまかせるから、膝立ちで固定する」
- 速く回させない。可動域を出すのが目的で、回数が目的ではない

**エラー動作の見分け方**（正面と側面から見る）

| 見えるもの | 意味 |
|---|---|
| 腰（骨盤）が先に回る ← **最多** | 骨盤と上体が分離できていない。動作4の割れが作れない状態 |
| 肩甲骨が動かない | 胸郭・肩甲骨の可動性不足。トップハンド主体になる根本原因 |
| 上体が傾いて頭の位置がずれる | 水平回旋になっていない |
| 身体全体が左右に動く | 支点が定まっていない |

**未成熟な年齢のため気をつけること**
- できない選手を責めない。ここは測る枠であって、できるようにする枠ではない
- 回旋量には大きな個人差がある。他人ではなく前回の自分と比べさせる
- 反動をつけさせない。無理に捻らせない

出典: 書籍 p052-053

### 肩甲骨の体操

**やり方**
①両腕を前で組んで両肘を伸ばし、トップハンドを上にして重ねる ②腕を上げ、肩をできるだけ耳に近づける ③両肘と腕で二等辺三角形をつくる ④三角形を崩さないまま、上に重ねた手を下の手より遠くへ持っていく ⑤手を逆にして反対方向も同様に。各方向5回。

**指導のポイント**
- 声かけは「三角形を崩さない」「上の手を遠くへ」の2つだけ
- 肩甲骨という言葉は使わなくてよい。形が保てているかだけを見る

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| 肩を上げても肩甲骨が背中側に寄らない | 肩甲骨の動きが悪い |
| 肩が前に出てしまう | 同上 |
| 二等辺三角形が崩れる（片方の肘の曲がりが違う） | 肩甲骨・胸郭の動きが悪い |
| 肩が上がってしまう | 同上 |

**未成熟な年齢のため気をつけること**
- 痛みが出る位置まで行かせない。成長期は関節周囲が硬い時期がある
- できない選手は回数を減らし、可動域を優先させる

出典: 書籍 p172-175

## 4. ドリル（15分）

**4つの動作を、この順で毎回通す。** 1本あたり3〜4分。

### 上体の角度 ─ 動作1（体重移動）

**やり方**
①自分の構えのスタンス幅で立つ ②軸足の外側から45度の方向に、足からバット1本分離してバットを立て、両手をグリップエンドの上に重ねる ③骨盤は倒れた状態を保ったまま、ウエストから上をバットの方向に乗せる ④この上体の角度を一切変えず、頭だけを動かして投手方向を見る ⑤上体の角度を変えないまま、踏み出し脚を引き寄せて軸脚に体重を乗せ、ステップする。形の確認5回 → ステップつき10回。

**段階**: 形の確認 → ステップつき → バットを持って

**指導のポイント**
- **「上体を後ろに残す」の定義をコーチが正確に持つ。骨盤の中心位置より頭が捕手寄りにある体勢で着地すること**
- 理由も言える。「外角の球に対して、振り出しからバットを加速させる距離を確保するため」
- 声かけは「**腰は前、頭は後ろ**」。この2語で誤解の大半を防げる

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| **軸脚に体重が残り、腰が前に進まない** ← **この年代で最も多く、最も警戒すべき** | 「上体を残す」を「体重を残す」と取り違えている |
| 後ろの肩がひどく下がっている | 両肩のラインはほぼ水平が正解 |
| 踏み出し脚から頭までが一直線にならない | 上体の角度が保てていない |

選手の自己申告も診断になる。この体勢をつくって「ものすごく後ろの肩が下がっている感じがする」と言う選手は、トップハンド主体の感覚が強い選手。

**未成熟な年齢のため気をつけること**
- **「上体を残せ」だけを言わない。必ず「腰は前へ」と対で言う。** 片方だけだと上の最多エラーを教えることになる
- 立てたバットが倒れて足に当たらない位置・向きを確認する

出典: 書籍 p132-135

### 左右対称スイング ─ 動作2（バット軌道）

**このメニューの中核。**

**道具**: プラスチックバット（書籍が小学生に対して明示指定）

**やり方**
①踏み出し脚を前に置き、その脚に全体重を乗せる。軸脚はバランスのためにつま先を触れているだけ ②ボトムハンド1本でバットを持ち、バットを立てた位置から真下へ振り下ろす ③テイクバックもフォローも同じ面から外れない。結果としてスイング軌道は左右対称になる。10スイング×2〜3セット。

**段階**: 片手・真下 → 両手・真下 → 両手・ベルト高
**崩れたら段階を戻す。先へ進めない。**

**指導のポイント**
- なぜ真下から始めるのかをコーチが理解しておく。①左右対称が確認しやすい ②**重力を利用するので、肩の筋力が弱くてもボトムハンドのリードが引き出せる** ③いつもの感覚を断ち切れる
- 声かけは「肩から先に動かす」。手を伸ばす動きから始めない
- 手首は返しにいかせない。「返るのは勝手に返る」
- **ストライクゾーンを打つドリルではない。** 書籍は「ストライクゾーンの球を打つことにこだわっていては何も変わらない」と明言している。実戦と違うことを気にしない

**エラー動作の見分け方**（**正面か真後ろから見る。左右対称かどうかは一目で分かる**）

| 見えるもの | 原因 | 対処 |
|---|---|---|
| 上体が横に倒れ、ヘッドが正面を向く | 肩をあごの下に入れる動きで上体が倒れている | 骨盤を正面に固定し直す |
| 斜めの軌道でしか振れない | 振り出しでボトムハンドの肩が動かず、トップハンドが勝っている | 段階を戻す |
| 手首だけで振っている | 上体の回旋が起きていない | 膝立ちの上体回旋に戻る |
| 片手ではできるのに両手で崩れる | トップハンドの優位 | 両手・真下に留める |
| 片手の時点で上体が倒れる | 肩甲骨・胸郭の可動性 | ストレッチ枠に戻す |
| トップハンドの肘を張って構えている | 肩甲骨の動きを殺している | 構えはニュートラルに |

正しくできている目安: **ボトムハンドの肩→腕→バットのラインが、地面に引いたラインと平行**。

**未成熟な年齢のため気をつけること**
- バットは「明らかに軽いと感じる」もの。金属バットは使わない
- スイング速度はバット重量より慣性モーメント（MOI）に依存し、学童では成人よりその依存が強い。「重い/軽い」ではなく「振れるか」で選ぶ
- 疲れて形が崩れたら止める。本数より1本の質
- **両手で持ち、実際に近い高さにした途端にトップハンド主体に戻るのがこの年代の典型。** 段階を飛ばすとトップハンド主体を上塗りするだけになる
- 「フォロースルーを大きく」と言わない。根本原因が変わらなければ大きくならない

出典: 書籍 p072-081

### トップのつくり方 ─ 動作3

3通りあるうち、最も簡単な方法を使う。

**やり方**
**バットを肩に担いで構え、一歩の踏み出しに合わせて、ボトムハンドの動きでグリップを引く。これだけ。** 10回×2セット。

**段階**: 形の確認 → 実際の構えから

**指導のポイント**
- **形を指示しなくてよいのが、この方法を使う理由。** 肩に担いだ構えでは、ヘッドは自然に頭の後ろ、トップハンドの肘は自然に下向きになる
- **トップは「高めの球に対する体勢」を基準に覚える。** 低めは後から派生で対応できる（テイクバックの動作は変えず、トップでのラインの角度だけを低めのプレーンに合わせる）
- **「構えでトップを作っておいて、あとは振るだけ」にしない。ステップに合わせて引くこと自体が、割れを生む**
- グリップの移動量はごくわずかでよい

**エラー動作の見分け方**

| 見えるもの | 原因 |
|---|---|
| ヘッド／グリップが投手方向に入りすぎる | テイクバックでトップハンドを働かせすぎ |
| グリップが背中側に深く入りすぎる | 骨盤と一緒に上体が回っている |
| ボトムハンドの肩が上がる | 肩甲骨が動かず肩が下がらない。ストレッチ枠に戻す |

**見た目が似ていても上の2つは原因が逆。処方も逆になるので、見極めてから声をかける。**

正しくできている目安: **グリップは前後に移動するが、骨盤は真横のまま前に進む**。

**未成熟な年齢のため気をつけること**
- **構えを直しに行かない。** 書籍は「構えの方法は自由」「すり足でも一本足でもどちらでも構わない」と明言している。望ましいトップに移行できていれば、構えには触れない

出典: 書籍 p144-147

### 割れをつくるステップ ─ 動作4

**やり方**
①両足を前後に大きく開いて構える ②両膝だけを投球方向に向けて曲げる ③両膝の向きを固定したまま上体を後ろに残す → 股関節が絞られ、骨盤が投手方向に対して真横になる ④頭の位置だけを動かして投手を見る ⑤軸脚の動きで骨盤を押し進め、一歩ステップする。形の確認5回 → バットあり10回。

**段階**: 形の確認 → バットを寝かせて持つ → 通常のスタンスから

**指導のポイント**
- **「割れ」の定義をコーチが持つ。ボトムハンド側の肩にストレッチがかかった状態**
- **量を指定する。「上体は深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらい」。世間で言う「割れ」より控えめ。大きく捻らせない**
- **タイミングを指定する。テイクバックは着地寸前に完了している。着地と同時ではない**
- 上体と骨盤をウエストを中心に逆にひねるのではない。股関節の動きで骨盤の向きをつくる
- バットを持つときは寝かせて構え、高めのレベルスイングを基準に置く

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| 骨盤や踏み出し脚の膝まで一緒に動く | 肩にストレッチがつくれず、割れができない |
| ステップ前に足を引く／上げる | その動きで骨盤の向きが変わってしまう |
| 着地してからテイクバックが終わる | タイミングが遅い |

膝の向きが崩れて割れが作れないのは、①肩を入れると骨盤まで動く（肩甲骨・胸郭）②股関節を引き込めない、のいずれかが原因のことがある。その場合はストレッチ枠の改善を並行させる。

**未成熟な年齢のため気をつけること**
- **分離を大きくする方向へ持っていかない。** 打撃は非対称・反復の回旋動作で腰椎に負荷がかかり、成長期は overuse のリスクが上がる。しかも打撃側には投球数制限に相当する公式ガイドラインが存在しない。書籍の量指定（肩を引き寄せる程度）を上限として運用する

出典: 書籍 p135-139、p084（割れの定義）

## 5. 置きT（10分）

**ティー打撃はドリルの延長。打ちごろの位置に置くのではない。**

**共通の条件**
- **はじめは「つくったスイングがそのまま出せる位置」にティーアップする。** 実際の打ちごろの位置ではない
- **高めから始め、ボトムハンド主体で打てるようになったら次第に低くする**
- 低めに移るときは、グリップを下げて振り上げるのではなく、低めに向かうスイングプレーンに合わせて振る

**内容**

| 順 | 内容 | 対応する動作 |
|---|---|---|
| 1 | **BOXスイングでティー**（軸脚を台に乗せたままティー打撃）10球 | 1 体重移動 |
| 2 | **高めのティー**（ドリルでつくった左右対称スイングをそのまま球に当てる）10球 | 2 バット軌道／3 トップ |

**BOXスイングの台**
高さ15〜40cm。ベンチ、踏み台、タイヤなど。**高さの選び方がこのドリルのすべて。「何も考えずに振っても、勝手に踏み出し脚に体重が乗り、勝手に骨盤の回転動作ができてしまう高さ」を選ぶ。** 初期ほど高い台を使い、次第に低くする。

**言葉で教えないのがこのドリルの利点。** 台の高さという環境の制約だけで動作を引き出す。コーチは高さを選ぶことに集中し、動作の指示はしない。

**エラー動作の見分け方**

**足元を見る。軸足は骨盤の動きを映す鏡。**

| 見えるもの | 意味 |
|---|---|
| 軸足のかかとがつま先より遠回りする | 骨盤のスライドが不足し、いきなり回旋している |
| 後ろ腰が遠回りに進む | 同上 |
| 台から降りるように振ってしまう | 台が高すぎる。低くする |
| ドリルでできた形が、球を置いた途端に崩れる | ティーの位置が「打ちごろ」になっている。位置を戻す |
| 低めでヘッドが下がって振り上げる | プレーンに合わせられていない |

**未成熟な年齢のため気をつけること**
- 台の安定を必ず確認する。ぐらつく台は使わない。周囲に人を入れない
- **身長差が大きい年代なので、台の高さを1つに固定しない。** 選手ごとに変えてよい
- 台の上で無理な体勢を作らせない。バランスを崩すようなら高さを下げる
- **球数を追わない。形が崩れた時点で止める。** 打撃側に球数の公式ガイドラインはないが、高練習量＋回復不足は成長期の腰椎リスクを上げる
- ティーと実投では体幹の動きが有意に異なる。**ティーだけで完結させない**

出典: 書籍 p085、p106-107、p120-121

## 6. フロントトス（15分）

**必ず入れる。** ティーとフロントトスでは学童の体幹の動きが有意に異なり、競技場面に近い形態を欠かすと転移しない（Bordelon et al. 2024、学童20名）。

**内容**
その日のドリルでつくった動きが、球が動く条件でも出るかを見る。10球×3セット程度。

**発展 ─ Offset Open**（動作2が形になってきたら導入）
スタンスの角度をずらして構え、深いところで球を捉えることを強制する。**最大のポイントは、その体勢で前傾（hinge）から抜け出さないこと。** Driveline の説明は「構えが変わってもスイングは変えない」で、書籍の「構えの自由度は高い」と思想が同一。

> 動画は未視聴（後述の未確認事項）。**導入前にコーチが動画を確認すること。**

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| **内角は打てるが、外角を待つと振れなくなる** | **コース対応の問題ではなく、上体の回旋不足の症状。** ストレッチ枠に戻す |
| バットが遠回りに出て、ヘッドの返りが早い | 同上 |
| 深い位置で捉えようとすると立ち上がる | 前傾から抜け出している |

**未成熟な年齢のため気をつけること**
- 速い球に移る判断はコーチがする。ただし**「遅い球だけ」を続けても速球には転移しにくい**（練習した球速・球種に特異的、という研究がある）。遅い球で形ができた選手から、速い球を少量ずつ混ぜる
- 安全管理は既存の `practice-batting.html` の運用ルールに従う（守備の1プレー完了まで次を投げない等）

出典: 書籍 p085／Bordelon et al. 2024／Kohmura et al. 2019／Driveline

## 7. 使う言葉と、言い換える言葉

身体部位ではなく対象や結果を指す言葉（外的焦点）のほうが運動学習を促進する。ただし基本動作を未獲得の初心者には身体部位の指示が効く場合もあり、この年代はその境目。**ドリル中は身体部位の指示、置きT・フロントトスでは外的な言葉**という使い分けにする。

### 使える言葉

| 言葉 | 使う場面 | 出典 |
|---|---|---|
| 「ヘッドを30m先まで一直線に伸ばすつもりで」 | スイング全般 | 書籍 p092 |
| 「ビーチボールを打つ」 | 斜めのプレーンを出したいとき | 書籍 p098 |
| **「地球からパワーをもらえぇ〜」** | 体重移動・下半身 | **チームの既存語彙**（Ameblo『地面反力って何？』）。既にチームで通じ、かつ外的な言葉になっている |
| 「腰は前、頭は後ろ」 | 上体の角度ドリル | 書籍 p132 から |
| 「三角形を崩さない」「上の手を遠くへ」 | 肩甲骨の体操 | 書籍 p172 |

### 言い換える言葉

| よく使われる言葉 | 問題 | 言い換え |
|---|---|---|
| **「上から叩け」** | 書籍は上から叩くことを否定し、「ダウンスイング」を**グリップの動きが上から下へ向かうこと**と再定義している | 「グリップから先に出す」。打球を上げる/下げるは技術の正誤ではなく作戦の選択として別に扱う |
| **「開くな」** | **開かないのは我慢の結果ではない。** 骨盤のスライドと素早い両肩の入れ替えが両立した結果 | 「後ろ腰をまっすぐ前へ」＋「肩を素早く入れ替える」の2つに分ける |
| **「フォロースルーを大きく」** | 根本原因が変わらなければ大きくならない | 言わない。ボトムハンドの働きを引き出すドリルを指示する |
| **「トップハンドで押し込め」** | **トップハンドに意識を持たせることはトップハンド主体を助長し、マイナスにしかならない。** この年代の大半は既にトップハンド主体 | 言わない。ボトムハンドの肩から動かす指示に置き換える |
| 「手首を返せ」 | 手首は自然に返る。返るのは肩の向きが変わり続けるから | 言わない |
| 「両目で見ろ／顔を正対させろ」 | 書籍は必須ではないとしている | 強制しない |

## 8. 最初に一度だけ行うこと

初回の練習で、全員に対して**主体の腕の判別**を行う。**この年代の大半はトップハンド主体である可能性が高い**ため、現状を把握してから始める。

| 方法 | やり方 | 判定 |
|---|---|---|
| 素振りでトップハンドを離す | フォロースルーでトップハンドを離す | ボトムハンド主体＝両腕のラインの延長線上にボトムハンドとバットが伸びる／トップハンド主体＝フォローの方向についていかない |
| トスバッティング | 10mくらい離れた相手にワンバウンドで返す。**身体に近い球**も投げる | ボトムハンド主体＝通常と同じように打ち返せる／トップハンド主体＝身体の近くでバットを振り込む必要が出る |

どちらも道具不要で、既存メニューの素振りとトスバッティングにそのまま乗る。

出典: 書籍 p014-019

## 9. このメニューに入れなかったもの

戻せるように理由を残す。

| 入れなかったもの | 理由 |
|---|---|
| 障害物スイング | **習得用ではなく確認用**。できていない選手にやらせると、当てまいとして振り上げる軌道を招く。動作2が定着してから再検討 |
| 縦振りドリル | 左右対称スイングで効果が出なかった選手への**次の一手**。必要になった選手にだけ個別に使う |
| 重りを用いた振りドリル | 10kgダンベルが例示されており明らかに成人向け。成長期の肩甲帯への加重は避ける |
| トップのつくり方②③ | ①で足りる。②③は**①でうまくいかない選手（特に肩が上がる選手）への代替**として個別に使う |
| 8の字（∞）テイクバック | ドリル→実打の最終ブリッジ。この段階では早い |
| スライド×回旋の補正ドリル（書籍 第8章6） | 第4章のドリルを大量に積んだ後の副作用補正。本メニューの分量では偏らない |
| Turn Behind The Ball（Driveline） | **top-hand only 制約が書籍の主張と正面から対立。** 対象年代（12〜14歳想定）も上回る |
| 5 Hitting Drills To Help Rotate Faster（Driveline） | 内容未確認。回旋パワー介入は12週規模で効果が出る一方、若年・低用量・8週では効果が出なかった報告がある。優先度が低い |
| Step Backs（Driveline） | **単独では使わない。** 後ろへのロードを強調するため、「軸脚に体重を残す」誤りへ振れるリスク。上体の角度ドリルと対で運用するなら可 |
| Feet Together Stride Away（Driveline） | 書籍の「両足をぴったり付けて1歩踏み出す」と同じ制約。**踏み出し脚を軸脚へ引き寄せてしまう選手が出たら**、その選手に個別に使う |
