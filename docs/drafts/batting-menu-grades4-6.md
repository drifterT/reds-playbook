# バッティング指導メニュー（小4〜小6）

**作成**: 2026-09-09 (水) JST
**対象**: 小学4〜6年生（10〜12歳）
**習得スキル**: S1 体重移動／S2 ボトムハンドの肩のリードによるスイング始動とスイングプレーン／S3 トップの作り方／S4 割れの作り方
**要件**: `batting-program-brief.md`
**出典**: `batting-book-notes.md`（K-01〜K-133）／`batting-instruction-evidence-review.md`（§番号）／`batting-driveline-notes.md`

## 0. 設計の考え方

**全ドリルは実施しない。** 書籍だけで50種以上あるドリルから、次の基準で選抜した。

1. S1〜S4 のどれに効くか言えること
2. 10〜12歳の筋力・可動性・集中で成立すること
3. **エラーがコーチの目で見えること**（打席横で判定できないドリルは、人数の多い学童練習では機能しない）
4. 枠の役割と一致すること
5. 出典自身の位置づけを守れること

**1日1テーマのローテーション**にした。理由は2つ。4スキルを毎回全部やると1つあたりの時間が足りず、どれも身につかない。そして10〜12歳の集中の持続を考えると、1回の練習で扱う新しい概念は1つが限度。

**「速く強く振る」は本メニューの対象外。** 既存メニュー側で確保されている（オーナー判断）。

## 2. ストレッチ枠（毎回・5分）

**一般的な柔軟ではない。** その日のドリルの前提となる可動性を測り、**選手に自分の現状を自覚させる枠**（K-24）。**できないこと自体が診断になる**のがこの2本を選んだ理由。

### ST-01 膝立ち上体回旋チェック

| | |
|---|---|
| **効くスキル** | S2・S4 の前提 |
| **やり方** | 膝立ちになる。骨盤と顔を正面に向けたまま、**上体だけを水平に回旋**させる。ゆっくり、最大可動域まで。左右交互。その後、同じことを立位でも行う |
| **設定** | 左右各5回 × 2セット／2分 |
| **出典** | 書籍 p052-053（K-22, K-23, K-24） |

**指導のポイント**

- 声かけは「**腰は動かさない。胸から上だけ回す**」
- **膝立ちで行う理由を選手に言う**：「立つと腰がごまかせるから、膝立ちで固定する」
- 速く回させない。**可動域を出すのが目的で、回数が目的ではない**

**エラー動作の見分け方**（正面と側面から見る）

| 見えるもの | 意味 |
|---|---|
| **腰（骨盤）が先に回る** ← 最多 | 骨盤と上体が分離できていない。S4の割れが作れない状態 |
| 肩甲骨が動かない | 胸郭・肩甲骨の可動性不足。トップハンド主体の根本原因（K-42） |
| 上体が傾いて頭の位置がずれる | 水平回旋になっていない |
| 身体全体が左右に動く | 支点が定まっていない |

**未成熟な年齢のため気をつけること**

- **できない選手を責めない。** この枠は測る枠であって、できるようにする枠ではない
- **回旋量には大きな個人差がある。** 他人と比べさせず、**前回の自分と比べさせる**
- **無理に捻らせない。** 反動をつけさせない

### ST-02 肩甲骨の意識付け体操

| | |
|---|---|
| **効くスキル** | S2・S3 の前提 |
| **やり方** | ①両腕を前で組んで両肘を伸ばし、**トップハンドを上にして重ねる** ②腕を上げ、肩をできるだけ耳に近づける ③**両肘と腕で二等辺三角形**をつくる ④三角形を崩さないまま、**上に重ねた手を下の手より遠くへ**持っていく ⑤手を逆にして反対方向も同様に |
| **設定** | 各方向5回／2分 |
| **出典** | 書籍 p172-175（K-120, K-121） |

**指導のポイント**

- 声かけは「**三角形を崩さない**」「**上の手を遠くへ**」の2つだけ
- 肩甲骨という言葉は使わなくてよい。**形が保てているかだけを見る**

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| 肩を上げても肩甲骨が背中側に寄らない | 肩甲骨の動きが悪い |
| **肩が前に出てしまう** | 同上 |
| **二等辺三角形が崩れる**（片方の肘の曲がりが違う） | 肩甲骨・胸郭の動きが悪い |
| **肩が上がってしまう** | 同上 |

**未成熟な年齢のため気をつけること**

- **痛みが出る位置まで行かせない。** 成長期は関節周囲が硬い時期があり、無理をさせる価値はない
- できない選手には**回数を減らして可動域を優先**させる

## 3. ドリル枠（15分・日替わり）

### 【A日】S2 バット軌道

#### DR-01 左右対称スイング — 片手・真下

**このメニュー全体の中核ドリル。**

| | |
|---|---|
| **効くスキル** | S2 |
| **道具** | **プラスチックバット**（書籍が小学生に対して明示指定。K-34） |
| **やり方** | ①踏み出し脚を前に置き、**その脚に全体重を乗せる**。軸脚はバランスのためにつま先を触れているだけ ②ボトムハンド1本でバットを持ち、バットを立てた位置から**真下へ振り下ろす** ③テイクバックもフォローも**同じ面から外れない**。結果としてスイング軌道は左右対称になる |
| **設定** | 10スイング × 3セット |
| **出典** | 書籍 p072-075（K-34〜K-41） |

**指導のポイント**

- **なぜ真下から始めるのかを、コーチが理解しておく**：①左右対称が確認しやすい ②**重力を利用するので、肩の筋力が弱くてもボトムハンドのリードが引き出せる** ③いつもの感覚を断ち切れる（K-39, K-40）
- 声かけは「**肩から先に動かす**」。**手を伸ばす動きから始めない**（K-37）
- **手首は返しにいかせない。**「返るのは勝手に返る」（K-38）
- **ストライクゾーンを打つドリルではない。** 書籍は「ストライクゾーンの球を打つことにこだわっていては何も変わらない」と明言（K-44）。実戦と違うことを気にしない

**エラー動作の見分け方**（**正面か真後ろから見る。左右対称かどうかは一目で分かる**）

| 見えるもの | 原因 | 対処 |
|---|---|---|
| **上体が横に倒れ、ヘッドが正面を向く** | 肩をあごの下に入れる動きで上体が倒れている | 骨盤を正面に固定し直す |
| **斜めの軌道でしか振れない** | 振り出しでボトムハンドの肩が動かず、トップハンドが勝っている | 段階を戻す。DR-01 が成立しない状態 |
| 手首だけで振っている | 上体の回旋が起きていない | ST-01 に戻る |

**正しくできている目安**: **ボトムハンドの肩→腕→バットのラインが、地面に引いたラインと平行**（K-36）。

**未成熟な年齢のため気をつけること**

- **バットは「明らかに軽いと感じる」もの**を使う。金属バットは使わない。書籍の指定どおりプラスチックバットでよい（K-34）
- スイング速度はバット重量より**慣性モーメント（MOI）に依存し、学童では成人よりその依存が強い**（Web §2-6）。「重い/軽い」ではなく「**振れるか**」で選ぶ
- 疲れて形が崩れたら止める。**本数より1本の質**

#### DR-02 左右対称スイング — 両手・真下 → 両手・ベルト高

| | |
|---|---|
| **効くスキル** | S2 |
| **やり方** | DR-01 と同じ動きを**両手**で行う（真下）。できたら**ベルトの高さ**へ向かう左右対称スイングに角度を上げる |
| **設定** | 両手・真下10本 → 両手・ベルト高10本 |
| **出典** | 書籍 p076-081（K-41, K-42） |

**指導のポイント**

- **段階を上げたどこで崩れるかが、そのまま診断になる**（K-41）
  - 片手・真下ではできるのに**両手で崩れる** → トップハンドの優位
  - **片手の時点で上体が倒れる** → 肩甲骨・胸郭の可動性（ST-01/ST-02 に戻す）
- **両手で持ち、実際に近い高さにした途端にトップハンド主体に戻る**のが、この年代の典型（K-42）。崩れたら段階を戻す。先へ進めない

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| ベルト高にすると斜め軌道になる | トップハンドが勝っている |
| テイクバックでグリップとヘッドを下げ、そこからすくい上げる | 同上（写真4-11 の型） |
| トップハンドの肘を張って構えている | 肩甲骨の動きを殺している。**構えはニュートラルに**（K-59） |

**未成熟な年齢のため気をつけること**

- **崩れたら戻す。先に進める判断をコーチがする。** 段階を飛ばすと、トップハンド主体を上塗りするだけになる
- 「フォロースルーを大きく」と言わない。**根本原因が変わらなければ大きくならない**（K-58）

### 【B日】S1 体重移動

#### DR-03 上体の角度ドリル（バット1本を立てる）

| | |
|---|---|
| **効くスキル** | S1 |
| **道具** | バット2本（1本は立てる用） |
| **やり方** | ①自分の構えのスタンス幅で立つ ②**軸足の外側から45度の方向に、足からバット1本分離してバットを立て**、両手をグリップエンドの上に重ねる ③骨盤は倒れた状態を保ったまま、**ウエストから上をバットの方向に乗せる** ④**この上体の角度を一切変えず、頭だけを動かして投手方向を見る** ⑤**上体の角度を変えないまま**踏み出し脚を引き寄せて軸脚に体重を乗せ、ステップする |
| **設定** | 形の確認5回 → ステップつき10回 |
| **出典** | 書籍 p132-135（K-83〜K-89） |

**指導のポイント**

- **「上体を後ろに残す」の定義を、コーチが正確に持つ**：**骨盤の中心位置より頭が捕手寄りにある体勢で着地すること**（K-83）
- 理由も言える：「**外角の球に対して、振り出しからバットを加速させる距離を確保するため**」（K-84）
- 声かけは「**腰は前、頭は後ろ**」。この2語で誤解の大半を防げる

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| **★ 軸脚に体重が残り、腰が前に進まない** | **この年代で最も多く、最も警戒すべき誤り**（K-85）。「上体を残す」を「体重を残す」と取り違えている |
| 後ろの肩がひどく下がっている | **両肩のラインはほぼ水平が正解**（K-87） |
| 踏み出し脚から頭までが一直線にならない | 上体の角度が保てていない（K-89） |

**選手の自己申告も診断になる**: この体勢をつくって「**ものすごく後ろの肩が下がっている感じがする**」と言う選手は、**トップハンド主体の感覚が強い選手**（K-88）。

**未成熟な年齢のため気をつけること**

- **「上体を残せ」だけを言わない。** 必ず「腰は前へ」と対で言う。片方だけだと K-85 の誤りを教えることになる
- 立てたバットが倒れて足に当たらない位置・向きを確認する

#### DR-04 BOXスイング（素振り）

| | |
|---|---|
| **効くスキル** | S1 |
| **道具** | **台**（高さ15〜40cm）。ベンチ、踏み台、タイヤなど |
| **やり方** | **軸脚を台の上に乗せて**素振りを行う。軸脚に体重を乗せた体勢からは振らず、**体重を前に進めながらテイクバックし、そこから振る** |
| **設定** | 10スイング × 2セット |
| **出典** | 書籍 p120-121（K-75〜K-76） |

**指導のポイント**

- **台の高さの選び方が、このドリルのすべて**：「**何も考えずに振っても、勝手に踏み出し脚に体重が乗り、勝手に骨盤の回転動作ができてしまう高さ**」（K-76）
- **初期段階ほど高い台を使い、次第に低くしていく**
- **言葉で教えないのがこのドリルの利点。** 台の高さという環境の制約だけで動作を引き出す（Web §2-5 の制約主導アプローチと一致）。**コーチは高さを選ぶことに集中し、動作の指示はしない**

**エラー動作の見分け方**

**足元を見る。軸足は骨盤の動きを映す鏡**（K-79）。

| 見えるもの | 意味 |
|---|---|
| 軸足のかかとがつま先より遠回りする | 骨盤のスライドが不足し、いきなり回旋している（K-78） |
| 後ろ腰が遠回りに進む | 同上 |
| 台から降りるように振ってしまう | 台が高すぎる。低くする |

**未成熟な年齢のため気をつけること**

- **台の安定を必ず確認する。** ぐらつく台は使わない。周囲に人を入れない
- **身長差が大きい年代なので、台の高さは1つに固定しない。** 選手ごとに高さを変えてよい（書籍も「身長により適切な高さは異なる」と明記）
- 台の上で無理な体勢を作らせない。**バランスを崩すようなら高さを下げる**

### 【C日】S3 トップ ＋ S4 割れ

#### DR-05 トップのつくり方①

**3通りあるうち、最も簡単な方法を選んだ。**

| | |
|---|---|
| **効くスキル** | S3 |
| **やり方** | **バットを肩に担いで構え、一歩の踏み出しに合わせて、ボトムハンドの動きでグリップを引く。これだけ** |
| **設定** | 10回 × 2セット |
| **出典** | 書籍 p144-147（K-97〜K-103） |

**指導のポイント**

- **形を指示しなくてよいのが、この方法を選んだ理由**。肩に担いだ構えでは**ヘッドは自然に頭の後ろ、トップハンドの肘は自然に下向き**になる（K-98）
- **トップは「高めの球に対する体勢」を基準に覚える**（K-96）。低めは後から派生で対応できる（K-115）
- **★「構えでトップを作っておいて、あとは振るだけ」にしない**（K-102）。**ステップに合わせて引くこと自体が、割れを生む**
- **グリップの移動量はごくわずかでよい**（K-101）

**エラー動作の見分け方**

| 見えるもの | 原因 |
|---|---|
| **ヘッド／グリップが投手方向に入りすぎる** | テイクバックで**トップハンドを働かせすぎ**（K-99） |
| **グリップが背中側に深く入りすぎる** | **骨盤と一緒に上体が回っている**（K-100） |
| ボトムハンドの肩が上がる | 肩甲骨が動かず肩が下がらない（K-105）。ST-02 に戻す |

**正しくできている目安**: **グリップは前後に移動するが、骨盤は真横のまま前に進む**（K-101）。

**未成熟な年齢のため気をつけること**

- **構えを直しに行かない。** 書籍は「構えの方法は自由」「すり足でも一本足でもどちらでも構わない」と明言している（K-103, K-111）。**望ましいトップに移行できていれば、構えには触れない**
- **見た目が似ていても原因が2つある**（上の表）。処方が逆になるので、どちらかを見極めてから声をかける

#### DR-06 割れをつくるステップ

| | |
|---|---|
| **効くスキル** | S4 ＋ S1 |
| **やり方** | ①両足を前後に大きく開いて構える ②**両膝だけを投球方向に向けて**曲げる ③**両膝の向きを固定したまま上体を後ろに残す** → 股関節が絞られ、**骨盤が投手方向に対して真横**になる ④頭の位置だけを動かして投手を見る ⑤軸脚の動きで骨盤を押し進め、一歩ステップする。**バットを持つ場合は寝かせて構え、高めのレベルスイングを基準に置く** |
| **設定** | 形の確認5回 → バットあり10回 |
| **出典** | 書籍 p135-139（K-90〜K-93） |

**指導のポイント**

- **「割れ」の定義をコーチが持つ**：**ボトムハンド側の肩にストレッチがかかった状態**（K-47）
- **★ 量を指定する**：**「上体は深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらい」**（書籍 p038）。**世間で言う「割れ」より控えめ**。大きく捻らせない
- **★ タイミングを指定する**：**テイクバックは着地寸前に完了している**（K-93）。着地と同時ではない
- 上体と骨盤を**ウエストを中心に逆にひねるのではない**。**股関節の動き**で骨盤の向きをつくる（K-91）

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| 骨盤や踏み出し脚の膝まで一緒に動く | **肩にストレッチがつくれず、割れができない**（K-46） |
| ステップ前に足を引く／上げる | その動きで**骨盤の向きが変わってしまう**（K-48） |
| 着地してからテイクバックが終わる | タイミングが遅い（K-93） |

**根本原因が別にある場合**: 膝の向きが崩れて割れが作れないのは、①肩を入れると骨盤まで動く（肩甲骨・胸郭）②股関節を引き込めない、のいずれかが原因のことがある。その場合は**ST-01/ST-02 の改善を並行させる**（K-95）。

**未成熟な年齢のため気をつけること**

- **★ 分離を大きくする方向へ持っていかない。** 打撃は非対称・反復の回旋動作で腰椎に負荷がかかり、成長期は overuse のリスクが上がる。**打撃側には投球数制限に相当する公式ガイドラインが存在しない**（Web §2-8）。書籍の量指定（肩を引き寄せる程度）を**上限**として運用する
- Driveline の "Unlocking **Power** Through Hip-Shoulder Separation" は分離を大きくする枠組みだが、**この年代では作り方だけを採り、大きくする方向は採らない**

## 4. 置きT枠（10分・日替わり）

**書籍はティー打撃をドリルの延長として位置づけている**（K-49）。**打ちごろの位置に置くのではない。**

### 全日共通の条件

- **★ はじめは「つくったスイングがそのまま出せる位置」にティーアップする**（K-49）。実際の打ちごろの位置ではない
- **★ 高めから始め、ボトムハンド主体で打てるようになったら次第に低くする**（K-66）
- 低めに移るときは、**グリップを下げて振り上げるのではなく、低めに向かうスイングプレーンに合わせて振る**（K-67）

### T-01（A日）高めから

DR-01/02 でつくった左右対称スイングを、そのまま球に当てる。**高めに固定**。10球×2セット。

### T-02（B日）BOXスイングでティー

**軸脚を台に乗せたままティー打撃**を行う（書籍も BOXスイングをティー打撃で行うと明記。K-75）。DR-04 の体重移動が球を打つ中でも出るかの確認。10球×2セット。

### T-03（C日）高め固定・トップ確認

高めに固定し、**着地寸前にテイクバックが終わっているか**だけを見る。10球×2セット。

**エラー動作の見分け方（全日共通）**

| 見えるもの | 意味 |
|---|---|
| ドリルでできた形が、球を置いた途端に崩れる | **ティーの位置が「打ちごろ」になっている**。位置を戻す |
| 低めでヘッドが下がって振り上げる | プレーンに合わせられていない（K-67） |
| 高めで詰まる | トップでのラインの角度が合っていない |

**未成熟な年齢のため気をつけること**

- **球数を追わない。** 形が崩れた時点で止める。打撃側には球数の公式ガイドラインがないが、**高練習量＋回復不足は成長期の腰椎リスクを上げる**（Web §2-8）
- ティーと実投では体幹の動きが有意に異なる（Web §2-5）。**ティーだけで完結させない**

## 5. フロントトス枠（毎回・15分）

**必ず入れる。** ティーとフロントトスでは学童の体幹の動きが有意に異なり、**競技場面に近い形態を欠かすと転移しない**（Web §2-5、Bordelon et al. 2024, 学童20名）。

### 基本

その日のドリルでつくった動きが、**球が動く条件でも出るか**を見る枠。10球×3セット程度。

### 発展：Offset Open（Driveline）

**S2 が形になってきたら導入する。**

- **スタンスの角度をずらして構え**、深いところで球を捉えることを強制する
- **最大のポイントは、その体勢で前傾（hinge）から抜け出さないこと**
- Driveline Japan の説明は「**構えが変わってもスイングは変えない**」。これは書籍 K-103/K-116（構えの自由度は高い）と思想が同一

> **⚠ 動画は未視聴**（egress 制限）。**導入前にコーチが実際に動画を確認すること**（[URL](https://www.youtube.com/watch?v=6t4FASZanQA)）。

**エラー動作の見分け方**

| 見えるもの | 意味 |
|---|---|
| **内角は打てるが、外角を待つと振れなくなる** | **★ コース対応の問題ではなく、上体の回旋不足の症状**（K-128）。ST-01 に戻す |
| バットが遠回りに出て、ヘッドの返りが早い | 同上 |
| 深い位置で捉えようとすると立ち上がる | 前傾から抜け出している |

**未成熟な年齢のため気をつけること**

- **速い球に移る判断はコーチがする。** ただし「遅い球だけ」を続けても速球には転移しにくい（Web §2-4、Kohmura et al. 2019 の球速特異性）。**遅い球で形ができた選手から、速い球を少量ずつ混ぜる**
- 安全管理は既存の `practice-batting.html` の運用ルールに従う（守備の1プレー完了まで次を投げない等）

## 6. 指導の言葉 — 使う言葉と、言い換える言葉

**外的焦点（身体部位ではなく、対象や結果を指す言葉）の方が運動学習を促進する**（Web §2-7）。ただし基本動作を未獲得の初心者には内的教示が効く場合もあり、**10〜12歳はその境目**。そこで**ドリル中は身体部位の指示、置きT・フロントトスでは外的キュー**という使い分けにする。

### 使える言葉

| 言葉 | 出典 | 使う場面 |
|---|---|---|
| **「ヘッドを30m先まで一直線に伸ばすつもりで」** | 書籍 K-56 | スイング全般 |
| **「ビーチボールを打つ」** | 書籍 K-62 | 斜めのプレーンを出したいとき |
| **「地球からパワーをもらえぇ〜」** | **チームの既存語彙**（Ameblo『地面反力って何？』） | 体重移動・下半身。**既にチームで通じる言葉であり、かつ外的焦点になっている** |
| 「腰は前、頭は後ろ」 | 本メニュー（K-83, K-85 から） | DR-03 |
| 「三角形を崩さない」「上の手を遠くへ」 | 書籍 K-120 | ST-02 |

### 言い換えが必要な言葉

| よく使われる言葉 | 問題 | 言い換え |
|---|---|---|
| **「上から叩け」** | 書籍は上から叩くことを否定。「ダウンスイング」を**グリップの動きが上から下へ向かうこと**と再定義している（K-52） | 「**グリップから先に出す**」。打球を上げる/下げるは技術の正誤ではなく**作戦の選択**として別に扱う |
| **「開くな」** | **開かないのは我慢の結果ではない。** 骨盤のスライドと素早い両肩の入れ替えが両立した結果（K-132, K-133） | 「**後ろ腰をまっすぐ前へ**」＋「**肩を素早く入れ替える**」の2つに分ける |
| **「フォロースルーを大きく」** | **根本原因が変わらなければ大きくならない**（K-58） | 言わない。ボトムハンドの働きを引き出すドリルを指示する |
| **「トップハンドで押し込め」** | **トップハンドに意識を持たせることはトップハンド主体を助長し、マイナスにしかならない**（K-04）。この年代の大半は既にトップハンド主体（K-03） | 言わない。ボトムハンドの肩から動かす指示に置き換える |
| 「手首を返せ」 | **手首は自然に返る。返しにいくものではない**（K-38）。返るのは肩の向きが変わり続けるから（K-123） | 言わない |
| 「両目で見ろ／顔を正対させろ」 | 書籍は必須ではないとしている（K-81） | 強制しない |

## 7. 落としたドリルと、その理由

**戻せるように理由を残す。**

| 落としたもの | 理由 |
|---|---|
| 障害物スイング（書籍 第4章5） | **習得用ではなく確認用**（K-71）。できていない選手にやらせると、当てまいとして振り上げる軌道を招く。S2 が定着してから再検討 |
| 縦振りドリル（書籍 第4章3） | 左右対称スイングで効果が出なかった選手への**次の一手**（K-54）。まず DR-01/02 を回す。必要になった選手にだけ個別に使う |
| 重りを用いた振りドリル（書籍 第8章4） | **10kgダンベルが例示**されており明らかに成人向け（K-125）。成長期の肩甲帯への加重は避ける |
| トップのつくり方②③（書籍 第7章2,3） | ①で足りる。②③は**①でうまくいかない選手（特に肩が上がる選手）への代替**として個別に使う |
| 8の字（∞）テイクバック（書籍 第4章 STEP7） | ドリル→実打の**最終ブリッジ**（K-65）。この年代・この段階では早い |
| 第8章6 スライド×回旋の補正ドリル | 第4章のドリルを大量に積んだ後の**副作用補正**（K-129）。本メニューの分量では副作用が出るほど偏らない |
| Turn Behind The Ball（Driveline） | **top-hand only 制約が書籍 K-04 と正面から対立**。対象年代（12〜14歳想定）も上回る |
| 5 Hitting Drills To Help Rotate Faster（Driveline） | 内容未確認（動画未視聴）。回旋パワー介入は12週規模で効果が出る一方、**若年・低用量・8週では効果が出なかった報告**がある（Web §2-2）。優先度が低い |
| Step Backs（Driveline） | **単独では使わない**。後ろへのロードを強調するため、K-85 の誤り（軸脚に体重を残す）へ振れるリスク。DR-03 と対で運用するなら可 |

## 8. コーチが最初に確認すること

**初回の練習で、全員に対して一度だけ行う。**

**主体の腕の判別**（書籍 K-06, K-07）。**この年代の大半はトップハンド主体である可能性が高い**（K-03）ため、現状を把握してから始める。

| 方法 | やり方 | 判定 |
|---|---|---|
| **①素振りでトップハンドを離す** | フォロースルーでトップハンドを離す | **ボトムハンド主体**＝両腕のラインの延長線上にボトムハンドとバットが伸びる／**トップハンド主体**＝フォローの方向についていかない |
| **②トスバッティング** | 10mくらい離れた相手にワンバウンドで返す。**身体に近い球**も投げる | **ボトムハンド主体**＝通常と同じように打ち返せる／**トップハンド主体**＝身体の近くでバットを振り込む必要が出る |

**どちらも道具不要で、既存メニューのトスバッティングと素振りにそのまま乗る。**
