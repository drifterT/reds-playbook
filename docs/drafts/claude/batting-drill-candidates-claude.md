## 1. 前提

オーナー指示（2026-09-09〜09-10）により確定した前提。

| 項目 | 内容 |
|---|---|
| 対象 | 10〜12歳（小4〜小6） |
| 編成 | 1グループ6〜7名、コーチ2名 |
| 枠 | 20分×2枠＝約40分 |
| **頻度** | **週2回（土日）** |
| **位置づけ** | **既存の打撃練習（最大2時間）に「追加」する基礎技術の習得・改善・向上ドリル** |
| 既存2hの中身 | 正面トス／フリーバッティング／シートバッティング |
| 練習全体 | 夏季 8:00-18:00、冬季 9:00-17:00 |
| 進級方式 | 採らない。毎回、全選手が同じ4本を反復する |
| 簡単形・標準形 | 日ごとの進級ではなく、**同一セッション内で選べるバリエーション**とする |
| 中心 | ストレッチ、身体をほぐす体操、身体の使い方のドリル、バットを持った動作ドリル |
| 実打撃 | **置きTによる「ボトムハンド側の肩と胸郭回転によるスイングリード」の確認まで** |
| 原典の扱い | 第一優先。外部資料を理由に原典ドリルを置き換えない |

### 4つの習得テーマ

1. 体重移動
2. ボトムハンド側の肩によるスイングリード
3. トップの作り方
4. 割れ／骨盤と胸郭の適切な時間差

### 共通基盤

適切な体重移動と姿勢を保ち、背骨付近を回転軸として胸郭を効率よく回し、その動きを肩・腕・バットへ伝えること。

**目標にしないもの**: 頭や骨盤の完全固定／腰だけの先行回転／前肩だけを引く動き／上体を無理に逆方向へ捻る動き。

### 「置きTまで」で原典の段階は切れていない

原典は置きT打撃の後を「足でリズムを合わせる動きを加え、個々の構え方から、実際のバッティング練習に移っていく」（p085）としている。**その接続先は既存2hの正面トス・フリー・シートが担う**ため、原典の段階を途中で切ることにはならない。

## 4. 暫定4本

各テーマに主担当を1本ずつ割り当てた。

### 【1】体重移動 ─ ステップ時の上体の角度（p132-135）

| 項目 | 内容 |
|---|---|
| 原典ページ | p132-135 |
| 仮称 | バット1本を立てて、上体の角度を覚える |
| 主目的 | 骨盤の中心位置より頭が捕手寄りにある体勢で着地する感覚を作る |
| 副次効果 | 姿勢維持、両肩の水平、割れの前提 |
| 共通基盤への寄与 | 「腰は前・上体は後ろ」を分離して体験させる。**共通基盤の「適切な体重移動と姿勢」そのもの** |
| 実施方法 | 軸足の外側45度・バット1本分離してバットを立て、両手をグリップエンドに重ねる → 骨盤は倒れた状態のままウエストから上をバット方向へ乗せる → **角度を変えず頭だけで投手を見る** → 角度を変えずにステップ |
| 器具 | 立てる用バット（2人1本で可、3〜4本）＋各自のバット |
| 運用 | **全員同時**。2列で相互観察 |
| 20分での回転 | 回転不要（全員同時）。**待ち時間ゼロ** |
| 1人あたり反復 | 形の確認5回＋ステップつき10回＝15回／約4分 |
| コーチ配置 | A＝横（軸脚に体重が残っていないか、踏み出し脚〜頭が一直線か）／B＝正面（両肩が水平か、頭の位置） |
| 成功条件 | 両肩のラインがほぼ水平／踏み出し脚から頭までが斜め一直線／腰が前へ進んでいる |
| 代償動作 | **軸脚に体重が残り腰が前へ進まない（原典が最多と名指し）**／後ろ肩が大きく下がる／上体の角度がステップ中に変わる |
| 安全性 | 立てたバットが倒れて足に当たらない配置。転倒リスクなし |
| 簡略化 | 立てるバットなしで「腰は前・頭は後ろ」だけを確認する形を同一セッション内で併用可 |
| 転移 | 原典は理由も明示（外角に対する加速距離の確保）。置きTへ持ち込める |

**選定理由**: 原典が**この年代で最も起きやすい誤りを名指ししている唯一の箇所**（「上体を残す」を感覚だけで捉えると「軸脚に体重を残す」という誤認識になり腰が前へ進まない、p132）。全員同時・器具ほぼ不要・観察点3つがすべて横から見える。

### 【2】ボトムハンドの肩によるスイングリード ─ 左右対称スイング（p072-081）

| 項目 | 内容 |
|---|---|
| 原典ページ | p072-081（バット選定は p072） |
| 仮称 | 真下に振り下ろす左右対称スイング |
| 主目的 | 軌道をフォロー側にシフトさせ、**ボトムハンドのリードを強制的に生み出す** |
| 副次効果 | スイングプレーンの角度合わせ、肩甲骨・胸郭の可動性の診断 |
| 共通基盤への寄与 | 胸郭回転→肩→腕→バットの伝達を、**重力で筋力不足を回避しながら**体験させる（p079） |
| 実施方法 | 踏み出し脚に全体重 → ボトムハンド1本でバットを立てた位置から**真下へ振り下ろす** → テイクバックもフォローも同じ面から外れない |
| 器具 | **プラスチックバット**（原典が小学生に対して明示指定、p072） |
| 運用 | **全員同時**（素振り）。置きT確認は2レーン |
| 20分での回転 | 素振りは回転不要。置きTは2レーン×5球×2巡で6〜7名を約6分 |
| 1人あたり反復 | 素振り30スイング（片手真下10／両手真下10／両手ベルト高10）＋置きT10球／約11分 |
| コーチ配置 | A＝**正面または真後ろ**（左右対称かは一目で分かる）／B＝横（肩→腕→バットのラインが地面と平行か） |
| 成功条件 | 肩→腕→バットのラインが地面のラインと平行（p075）／軌道が左右対称 |
| 代償動作 | 上体が横に倒れヘッドが正面を向く／斜めの軌道でしか振れない／手首だけで振る／両手にした途端に崩れる |
| 安全性 | プラバットのみ。間隔2m。金属バットを使わない |
| 簡略化 | **片手真下 → 両手真下 → 両手ベルト高の3段階を同一セッション内で選択**。崩れたら段階を下げる |
| 転移 | 置きTまでで成立。ただし原典は「はじめは**つくったスイングがそのまま出せる位置**にティーアップ」と条件を付けている（p085） |

**選定理由**: 原典の中核。**段階を上げたどこで崩れるかがそのまま診断になる**（p072-079）という、他に代えがたい性質を持つ。左右対称かどうかは正面から一目で判定でき、6〜7名でもコーチ1名が全員を見られる。

### 【3】トップの作り方 ─ トップのつくり方①（p144-147）

| 項目 | 内容 |
|---|---|
| 原典ページ | p144-147（判定基準は p157 を併用） |
| 仮称 | 肩に担いで、一歩に合わせて引く |
| 主目的 | ステップと同期したテイクバックで、望ましいトップへ移行する |
| 副次効果 | 割れの生成、骨盤と上体の分離 |
| 共通基盤への寄与 | **形を指示せずにトップが決まる**。担いだ構えではヘッドが自然に頭の後ろ、肘が自然に下向きになる |
| 実施方法 | **バットを肩に担いで構え、一歩の踏み出しに合わせてボトムハンドの動きでグリップを引く。これだけ** |
| 器具 | バット1本／人 |
| 運用 | **全員同時**。間隔2m |
| 20分での回転 | 回転不要。**待ち時間ゼロ** |
| 1人あたり反復 | 10回×2セット＝20回／約4分 |
| コーチ配置 | A＝横（グリップが投手方向へ入りすぎ／背中側へ入りすぎ）／B＝正面（骨盤が真横のまま前へ進んでいるか） |
| 成功条件 | **グリップは前後に移動するが骨盤は真横のまま前へ進む**（p146）／肩→バットのラインが高めのプレーンと一致（p157） |
| 代償動作 | **ヘッドが投手方向へ入りすぎ＝トップハンドの働きすぎ**／**グリップが背中側へ深く入る＝骨盤ごと上体が回っている**（p145-146。**原因が逆なので処方も逆**）／ボトムハンドの肩が上がる |
| 安全性 | バットを持った全員同時なので間隔管理のみ |
| 簡略化 | ①が最も簡単な方法。うまくいかない選手には②（p148-151）③（p152-153）を個別に |
| 転移 | 原典は「トップは高めの球に対する体勢を基準に覚え、低めは派生」（p142, p158）としており、置きTの高さ設定と直結 |

**選定理由**: 原典が3通り示すうち**最も簡単**と明記した方法。手順が1行で済み、説明過多を避けられる。エラーの原因が2つに切り分けられているため、コーチ2名で分担して見られる。

### 【4】割れ／骨盤と胸郭の時間差 ─ 割れをつくるステップ（p135-139）

| 項目 | 内容 |
|---|---|
| 原典ページ | p135-139（定義は p084、量の指定は p038） |
| 仮称 | 両膝を固定して、上体を後ろに残す |
| 主目的 | **ボトムハンド側の肩にストレッチをかける**（原典の「割れ」の定義） |
| 副次効果 | 体重移動、トップのタイミング |
| 共通基盤への寄与 | 骨盤と胸郭の時間差を、**股関節の動き**で作る（ウエストを中心に逆ひねりしない、p136） |
| 実施方法 | 両足を前後に開く → **両膝だけを投球方向に向けて曲げる** → **両膝の向きを固定したまま上体を後ろに残す**（股関節が絞られ骨盤が投手に対して真横になる）→ 頭だけ動かして投手を見る → 軸脚の動きで骨盤を押し進めて一歩 |
| 器具 | バット1本／人（形の確認段階は不要） |
| 運用 | **全員同時** |
| 20分での回転 | 回転不要。**待ち時間ゼロ** |
| 1人あたり反復 | 形の確認5回＋バットあり10回＝15回／約5分 |
| コーチ配置 | A＝正面（骨盤・膝が一緒に動いていないか）／B＝横（**着地寸前にテイクバックが終わっているか**） |
| 成功条件 | 骨盤が投手に対して真横／膝の向きが変わらない／**テイクバックが着地寸前に完了**（p137） |
| 代償動作 | 骨盤や膝まで一緒に動く／ステップ前に足を引く・上げる（骨盤の向きが変わる）／着地してからテイクバックが終わる |
| 安全性 | **量の上限を守ること。「上体は深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらい」（p038）** |
| 簡略化 | 膝の向きが崩れる選手には、つま先の向きを変えたバリエーション（p140-141）を同一セッション内で |
| 転移 | バットを持つ段階では高めのレベルスイングを基準に置く（p136-137）。置きTの高さと一致 |

**選定理由**: 原典が「割れ」という語を自ら使い、その中身を定義している唯一の系統（p084）。**タイミングと量の両方が指定されている**数少ないドリル。

## 7. 判断点 ─ 「身体をほぐす体操」を4本に入れるか

**私の判断で決めず、突合で扱うべき点。**

作業依頼は「**ストレッチ・身体をほぐす体操・身体の使い方を中心とする**」としているが、4テーマ（体重移動／リード／トップ／割れ）には体操が含まれない。1:1対応で4本を選ぶと、**身体をほぐす体操が1本も入らない**。

一方、原典は次のように述べている。

> **「手打ち」の原因は腕の使い方ではなく、上体の回転動作の不足**（胸郭・肩甲骨が動かないこと）（p052）

> 左右対称に振れない主因は、**肩甲骨・胸郭の動きの悪さ**。「ボトムハンド主体に振ろう」と思っても、肩がプレーン方向に一致しなければ振れない（p080-081）

つまり**原典において、可動域は4本すべての前提条件**である。可動域が足りない選手には、【2】も【4】も成立しない。

### 選択肢

| 案 | 構成 | 得失 |
|---|---|---|
| **A** | 4本＋枠外の導入3分（膝立ちの上体回旋 p052-053） | 4テーマ1:1を維持しつつ前提を確保。**Claude の推奨** |
| B | 4本のうち1本を体操にし、トップと割れを1本に統合 | 原典上、トップと割れは**同一の動作（ステップと同期したテイクバック）の2つの側面**（p147）なので統合は原典に忠実。ただしテーマとの対応が3:4になる |
| C | 4本を1:1で維持し、体操は扱わない | 依頼の「体操を中心に」と矛盾。原典の前提条件も満たさない |

時間は足りる。4本の合計が約24分なので、導入3分を足しても27分。40分に対して13分の余裕が残る。

## 8. 因果関係の反証

依頼の共通基盤の定義と原典を突き合わせ、**誤解が生じうる箇所**を5点報告する。

### ① 「骨盤の完全固定を目標にしない」と原典は矛盾しない

原典は複数のドリルで「骨盤を正面に固定したまま」と指示する（p052, p058, p076）が、**目標動作としては明確に否定している**。

> 骨盤は「スライド動作」だけを行うつもりでも、**上体が回旋すれば骨盤も回転します。……そこは気にすることはなく**（p188）

**原典の骨盤固定は「ドリルの制約」であって「目標の形」ではない。** ここを取り違えると、依頼が避けたい「腰を止めて上体だけ捻る」指導になる。

### ② 「前肩だけを引く」— 原典では引く場面と押す場面が逆方向

原典はテイクバックで「ボトムハンド側の肩をあごの下に**引き寄せる**」（p032, p038）と言い、スイングでは「あごの下に引き入れたボトムハンドの肩を**押していく**動きから始める」（p061, p076）と言う。

**引くのはテイクバック、押すのはスイング。** 混同すると「前肩を引いて振る」という、依頼が避けたい動きをそのまま教えることになる。原典自体はこの誤りを犯していないが、**指導語に変換するときに最も混ざりやすい箇所**。

### ③ 「素早く回す」と「深く捻る」は別の量

原典が求めているのは速さであって、大きさではない。

> 骨盤はスライドのつもりで、それでも十分に回旋し後ろ腰を直進させる × **限りなく素早く**両肩を入れ替える（p190）

> 上体は本来あまり**深く捻らなくてよい**（p038）

依頼の「胸郭を**効率よく**回す」はこの区別と一致する。逆に「割れを大きく」は原典が明示的に否定している方向。

### ④ 「ボトムハンドの肩がリードする」は結果の記述であって、指示ではない

**指導語への変換で最も危険な箇所。**

> **トップハンドの肘をあごの前に入れにいくのではなく**、肩甲骨・胸郭が動いて結果としてそうなる（p183）

「肩でリードしろ」と選手に言うと肩の単独操作になり、原典の意図と逆になる。原典が用意しているのは**選手への指示ではなく、コーチの観察語**である。判定は「肩→腕→バットのラインが地面のラインと平行か」（p075）という**見える形**で行い、選手への言葉は別に作る必要がある。

### ⑤ 「内角は打てるが外角が打てない」は可動域不足の症状

> 上体の回旋が悪く骨盤と上体が一体でしか動かないと、**内角を打てるほどにしか対応できず、外角を待つとほぼ振れなくなる**（p184）

これは**コース対応の問題ではなく可動域不足**という因果。既存2hのシートバッティングで外角に振れない選手が出たとき、コース別の打ち方を教える方向へ行かず、追加40分の可動域側へ戻す——という接続ができる。**既存メニューと追加ドリルをつなぐ実用的な観察点。**

## 9. 確認が必要な事項

### 累積負荷（土日連続）

打撃系は1日あたり最大2時間40分（既存2h＋追加40分）、それが**土日連続**になる。

打撃側には投球数制限に相当する公式ガイドラインが存在せず、一方で成長期・高練習量・回復不足が腰椎の overuse リスクに関わることは複数の資料が示している。**判断材料として3案を挙げる。**

1. 土日とも同じ4本（依頼の「毎回同じ4本を反復」に最も忠実）
2. 土＝4本フル、日＝反復数を減らす（同じ4本のまま量だけ調整）
3. 追加40分の分、既存2hの側を短縮する
