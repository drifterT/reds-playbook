## 2. 3者の一致点 — 確定扱いにできるもの

独立に到達した結論なので、以後は前提として扱う。

### 2-1 「下の手の肩がリードする」は、選手への指示ではない

- **Claude**: 原典 p183「トップハンドの肘をあごの前に入れにいくのではなく、肩甲骨・胸郭が動いて結果としてそうなる」→ **コーチの観察語であって指示ではない**
- **Codex**: 「前肩だけを腕力で引く、肩をすくめる、脇を締め続けるという意味ではない。胸郭回転に伴って肩が運ばれ、その後に腕とバットがついてくる現象を表す**観察語**として扱う」
- **Perplexity**: 「『右肩を顎の下へ入れろ』は、最初の主な指示にはしない。右肩を落とす、首を傾ける、腰を反る、顔を早く切るといった誤った動作を作るおそれがある」

→ **確定。選手に「肩でリードしろ」と言わない。**

### 2-2 「割れ」を大きくすることは目標にしない

- **原典 p038**: 「上体は本来あまり深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらいの方が効果的」
- **Codex**: 「選手間で分離角度を競わせない」
- **Perplexity**: 「10〜12歳では、分離角の最大化を狙うより、姿勢、荷重、静かな着地、上体から肩・腕・バットへの連続性を優先」

→ **確定。量の上限は原典 p038。**

### 2-3 原典の「骨盤を固定」はドリルの制約であって、目標の形ではない

- **原典 p188**: 「骨盤はスライド動作だけを行うつもりでも、上体が回旋すれば骨盤も回転します。……そこは気にすることはなく」
- **Codex**: 「原典の足・膝・骨盤の制約は感覚を引き出すためのドリル条件であり、実際のスイングで骨盤を固定する指示ではない」
- **Perplexity**: 「骨盤を完全に固定すること」を目標として誤解させない

→ **確定。**

### 2-4 置きティーは動作確認の工程であって、打球数を稼ぐ場ではない

- **原典 p085**: 「はじめのうちは、つくったスイングがそのまま出せる位置にティー・アップする」
- 3者一致。**その先（正面トス・フリー・シート）は既存2hが担う。**

### 2-5 共通の準備（可動域）は4本の外に置く

- **Claude**: 4本＋枠外の導入3分（案A）
- **Codex**: 「2〜3分の準備として有用だが、4テーマの独立1本とは数えない」
- **Perplexity**: A分類（共通基盤）を独立させている

→ **確定。私が §7 で挙げた判断点はこれで解決。案Aを採る。**

## 3. 相違点と決着

### 3-1 体重移動の主担当 ─ p066-069（Codex）を採る

**Codexの指摘に対し、原典 p066-069 を400dpiで再読して検証した。**

原典 p066 の実際の記述:

> まず、肩幅程度のスタンスで重心はほとんど沈めずに立ち、上体は「3. 上体の回転の体操からのドリル展開」STEP1と同様に、2つの体勢どちらかで構え、顔だけを投手方向に向けておきます（写真3-17〜3-20各A）。そこから、**真横にただ一歩踏み出すだけのステップに合わせて、ボトムハンドの肩をあごの下に引き寄せ**（各B〜C）、着地した瞬間に、下半身では**骨盤を横向きに近い状態のまま踏み出し脚方向に移動させる「スライド動作」から始まる回旋動作**を、上半身では**両肩を一瞬で入れ替える回転動作**を、同時に行います（各D〜F）。

**採る理由**

1. **体重移動そのものが原典の言葉で定義されている**——「骨盤を横向きに近い状態のまま踏み出し脚方向に移動させるスライド動作」。私が選んだ p132-135 は、体重移動そのものではなく**その最中の上体の角度**を扱うドリル
2. **1本で基盤が揃う**——スライド（体重移動）＋両肩の入れ替え（上体の回転）＋肩をあごの下（割れの前提）が同時に入る
3. **バットなし・全員同時**——6〜7名の運用で最も強い
4. **原典の構造上、これが土台**——第2章 STEP3（p027-031）の骨盤の回旋に上体の回転を重ねたものが p066-069。第6章の2本はその上に載る修正

**p132-135 を落とすことで失うもの、およびその手当て**

p132-135 には、他に代えがたい2つの内容がある。**基盤ドリルの観察点として取り込む。**

| 内容 | 原典 | 取り込み先 |
|---|---|---|
| **この年代で最も多い誤りの名指し**——「上体を後ろに残す」を感覚だけで捉えると「軸脚に体重を残す」という誤認識になり、腰が前に進まなくなる | p132 | 【1】の見るポイントへ |
| **具体的な目標**——立てたバットの方向にお辞儀をして、**重ねた手の真上におでこをかぶせる** | p133 | 【1】が崩れる選手への個別修正として保持 |

p132-135 自体は**個別修正**に降格する（Codexの分類に合わせる）。

## 4. 3者に共通して残る問題 ─ 第6章の2本は「特定の選手のためのドリル」

**これは3者とも扱いきれていない。**

原典の書き出しを高解像度で確認したところ、第6章の2本はどちらも対象を限定している。

> **p135（割れをつくるステップ）**: これは、**特に、着地時にどうしても踏み出し脚の膝が内に向いてしまって**、上半身との間に十分な「割れ」をつくれない選手のためのドリルです。

> **p133（上体の角度）**: ……**ない選手によく行うドリルです**（前段が「上体を後ろに残せない」等の限定と読める）

対して、採用した他の3本は限定がない。

> **p145（トップのつくり方①）**: はじめに紹介するのは、**最も単純で誰でも簡単に行える方法**です。……**一からスイング動作を正しくしていく場合に、よく用いている**ものです。

**つまり、【4】割れ（p135-139）は、原典では「全員が毎回やるドリル」ではなく「膝が内に向く選手のための修正ドリル」。**

### どうするか（判断が要る）

| 案 | 内容 | 得失 |
|---|---|---|
| **A** | p135-139 をそのまま【4】に採る | 原典が「割れ」を定義し、量（p038）とタイミング（p137）を指定している唯一の系統。**ただし原典の位置づけを変えて使うことになる** |
| B | 【1】p066-069 が割れを含む（肩をあごの下＋骨盤は真横）ので、【4】の枠を別のものに使う | 原典に忠実。ただし割れの専用枠がなくなる |
| C | 【4】を第2章 STEP4（p031-040、捻れの説明がある）に置き換える | 限定のない基礎章。ただし p036-039 の記述は未検証 |

**私の推奨はA**（実用上、割れの量とタイミングを明示している箇所は他にない）。**ただし「原典では対象を限定したドリルである」ことを資料に明記する**条件付き。

Codexの判断を仰ぎたい。

## 5. 統合4本の要領

**※ 実施方法は §3-2 の検証済み記述に基づく。未検証の箇所は明記した。**

### 準備（4本の外・3分）

**膝立ちの上体回旋（p052-053）**
膝立ちになり、骨盤と顔を正面に向けたまま、上体だけを水平に回す。左右交互。その後、立位でも行う。
- **見るポイント**: 腰（骨盤）が先に回っていないか（最多）／肩甲骨が動かない／上体が傾いて頭がずれる
- **注意**: できない選手を責めない。ここは測る枠

**肩甲骨の動きの意識付け（p172-175）**
両腕を肩の高さで前に伸ばし、上の手を下の手に重ねる。**二等辺三角形を崩さないまま、上の手を下の手より遠くへ持っていく。** 目標は**なるべく少ない腕の動きで、肩をあごの下に入れる**こと。手を逆にして反対方向も。
- **その場でわかる診断**: 腕を上げただけで肩甲骨が自然に前へ出ない選手は、**横から見て肩が背中へ引け、お腹が突き出た体勢**になる。その場合は意識的に肩甲骨を前へ突き出して構えるところから始める
- **悪い動き2つ**: 二等辺三角形が崩れる（写真8-7）／肩が上がってしまう（写真8-8）
- **なぜこれをやるか**: 「肩をあごの下に入れる」は【1】【4】でそのまま使う動きで、**準備と本編が同じ言葉でつながる**

### 【1】体重移動 ─ 一歩ステップ＋骨盤と上体の回転（p066-069）

**やること**
肩幅程度のスタンスで、重心はほとんど沈めずに立つ。顔だけ投手方向へ。**真横にただ一歩踏み出す**。その一歩に合わせて**下の手の肩をあごの下へ引き寄せる**。**着地した瞬間に、腰を横向きのまま踏み出し脚の方向へ運びながら回し、同時に両肩を一瞬で入れ替える。**

- **器具**: なし（バットを持たない）
- **運用**: 全員同時、2列。待ち時間ゼロ
- **反復**: 5回×2セット／約6分
- **コーチA（正面）**: 頭が横へ流れていないか／踏み出し脚の膝が内へ崩れていないか
- **コーチB（横）**: **軸脚に体重が残って腰が前へ進んでいないか**（p132 が名指しする最多の誤り）／後ろ腰がまっすぐ前へ進んでいるか
- **できている形**: 腰は横向きのまま前へ運ばれ、両肩が入れ替わっている
- **選手に言う言葉**: 「小さく一歩」「下の手の肩をあごの下へ」「足が着いたら、腰と肩を入れ替える」
- **言わない**: 「腰だけ先に回せ」「頭を後ろに残せ」「強くねじれ」
- **崩れる選手への個別修正**: p132-135（立てたバットにお辞儀して、重ねた手の真上におでこをかぶせる）

### 【2】下の手の肩によるスイングリード ─ 左右対称スイング（p072-085）

**やること**
**立てたバットの真上に頭がくるように立つ。** 両足は踏み出す脚が前で、**その脚に全体重を乗せ、後ろの脚はバランスのためにつま先を床に触れさせておくだけ**。下の手1本でバットを握り、**バットを立てていた位置（頭の真下）を中心に、振り子のように左右へ揺らす**。**ヘッドの動きが、つま先を向けた正面方向に完全に直交するようにする。** そこから実際に振る。

- **段階（同一セッション内）**: 片手・真下 → 両手・真下 → 両手・ベルトの高さ。**崩れたら段階を下げる**
- **器具**: **小学生はプラスチックバット**（原典 p072 の明示指定）。一度できるようになれば通常のバットで構わない
- **運用**: 素振りは全員同時。置きティーはネット2面
- **反復**: 素振り約30／置きティー5球×2巡／約11分
- **コーチA（正面または真後ろ）**: 左右対称に振れているかは一目でわかる
- **コーチB（横）**: 下の手の肩→腕→バットのラインが、地面に引いたラインと平行か（p075）
- **できている形**: 軌道が左右対称／ラインが地面と平行
- **選手に言う言葉**: 「肩から先に動かす」「手だけでバットを放り出さない」「返そうとしない。勝手に返る」
- **注意**: **ストライクゾーンを打つドリルではない**（p082「ストライクゾーンの球を打つことにこだわっていては何も変わらない」）
- **置きティーの条件**: **つくったスイングがそのまま出せる位置**に置く。打ちごろの位置ではない（p085）。**高めから始め、できるようになったら次第に低くする**（p106）

### 【3】トップの作り方 ─ トップのつくり方①（p144-147）

**やること**
**バットを横に寝かせた状態で肩に乗せ、肩幅程度の狭いスタンスでリラックスして立つ。そこから一歩の踏み出しに合わせて、下の手の動きでグリップを引く。これだけ。**

- **なぜこれか**: 肩に担いだ構えでは、**ヘッドは自然に頭の後ろ、上の手の肘は自然に下向き**になる。**形を指示しなくても決まる**（p145）
- **器具**: バット1本／人。最初はプラスチックバットか軽いバット
- **運用**: 全員同時、間隔2m。待ち時間ゼロ
- **反復**: 区切り動作3回 → 連続動作3〜5回、2セット／約4分
- **コーチA（横）**: ヘッドやグリップが投手方向へ入りすぎていないか／グリップが背中側へ深く入りすぎていないか
- **コーチB（正面）**: 骨盤が投手に対して真横のまま前へ進んでいるか
- **できている形**: **グリップは前後に移動するが、骨盤は真横のまま前へ進む**（p146）
- **エラーの原因は2つあり、逆**: 投手方向へ入りすぎ＝**上の手の働きすぎ**／背中側へ深く入る＝**骨盤ごと上体が回っている**。**処方が逆になるので見極めてから声をかける**
- **選手に言う言葉**: 「足といっしょにグリップが離れる」「手だけを後ろへ引かない」
- **構えは直しに行かない**: 原典は「構えの方法は自由」「すり足でも一本足でもどちらでも構わない」としている

### 【4】割れ ─ 割れをつくるステップ（p135-139）

**※ §4 の判断待ち。原典では対象を限定したドリル。**

**やること**
**両足を付けたスタンスで、両股関節を後ろに引き込みながら軽く膝を曲げて構える。** 次に、**両膝だけを投球方向側に向きを変える。** その膝の向きを固定しておくつもりで、**上半身を膝と逆の45度方向にわずかにかぶせる。** そこからステップし、**着地で割れをつくる**。

- **原典が対象とする選手**: 着地時に**踏み出し脚の膝が内に向いてしまって**割れをつくれない選手（p135）
- **量の上限**: 「上体は深く捻らなくてよい。下の手側の肩を引き寄せるくらい」（p038）。**分離を大きくする方向へ持っていかない**
- **タイミング**: **グリップを引く動きは、着地寸前の時点で終わっている**（p137）
- **器具**: 最初はバットなし。次にバット1本／人
- **運用**: 全員同時、2列
- **反復**: 形の確認4〜5回 → バットあり10回／約5分
- **コーチA（正面）**: 骨盤や膝まで一緒に動いていないか
- **コーチB（横）**: 着地寸前にグリップを引き終わっているか／腰が反っていないか
- **選手に言う言葉**: 「足を運ぶ間は、胸を早く見せない」「足が着いたら回る」
- **崩れる選手への個別修正**: p140-141（つま先の向きを変えたバリエーション）

## 6. 40分の運用

4本の合計は約26分。準備3分を足して29分。**40分に対して11分の余裕**があり、説明・交代・球拾い・移動に充てられる。

### 第1枠（20分）

| 時間 | 内容 |
|---|---|
| 0:00-3:00 | 準備（膝立ちの上体回旋／肩甲骨） |
| 3:00-9:00 | 【1】一歩ステップ＋骨盤と上体の回転 |
| 9:00-14:00 | 【4】割れをつくるステップ |
| 14:00-18:00 | 【3】トップのつくり方① |
| 18:00-20:00 | 共通の確認・移動 |

### 第2枠（20分）

| 時間 | 内容 |
|---|---|
| 0:00-8:00 | 【2】左右対称スイング（素振り。片手→両手→ベルトの高さ） |
| 8:00-18:00 | 【2】置きティー（ネット2面、1人5球×2巡） |
| 18:00-20:00 | 通常の構えでの素振り、共通の一言 |

### 置きティーの回転（Codexの計算を採用）

7名×5球＝35スイング。2レーンに分けると混雑側で18スイング。1球あたり15秒（セット・スイング・短い一言）で純粋な打撃時間は約4分30秒。交代と説明を含めても10分に収まる。

**打者以外を待機にしない。** 次の打者はバットなしで同じ肩の入れ替えを2〜3回。残りは安全線の後ろでペア観察。ティー係は**バットが完全に止まってから**入る。

### コーチ2名

- **A＝正面寄り**: 頭の横流れ、踏み出し脚の膝の崩れ、胸が早く開くこと、打球方向
- **B＝側方**: 踏み出しの幅、着地、腰の反り、腰から肩・腕へつながる順序
- **1回のフィードバックは1項目だけ**

### 土日の扱い

**4本を入れ替えない。毎回同じ順序。** 当日の共通課題に応じて各ドリルの時間を1〜2分動かす。個人差にはドリルを変えるのではなく、**動作を小さくする／バットを外す／プラスチックバットに戻す／途中で一度止める**で対応する。

**土日連続の累積負荷は未決**（既存2h＋40分が2日連続）。判断材料は §8。

## 7. 言葉のルール

**Perplexity §4 を採用する。** 詳細は `batting-glossary.md`。

- **「キュー」を使わない** → 「選手に言う言葉」「その場で伝える言葉」
- **「ネットを向く」「胸をネットへ回す」を使わない** → **投手方向／一塁側／三塁側**で書く。**右打者基準。左打者は左右を反転する**と明記する
- 専門用語は平易な言葉を先に置き、括弧で補う（例：胸から腰までの上体（胸郭））
- **6つを混ぜない**: 選手に言う言葉／コーチが見る確認項目／できたかの最終的な見え方／専門的な補足／外部資料が確認している事実／少年向けの翻訳提案

> **Codex案・Perplexity案とも「キュー」を使っている。** 統合資料では置き換える。
