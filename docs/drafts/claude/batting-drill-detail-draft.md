## この資料の言葉づかい

野球経験のないコーチが読んで、そのまま使えることを優先した。

- **方向はすべて右打者を基準に書く。左打者は左右を反転する。**
- 方向は**投手方向／一塁側／三塁側**の3つだけで書く。
- **「引き手」＝グリップの下側の手**（右打者なら左手。原典の「ボトムハンド」）。**「押し手」＝上側の手**（右打者なら右手。利き手側。原典の「トップハンド」）。
- 「腰」は骨盤のこと。「胸から腰までの上体」は胸郭のこと。専門語は括弧で添えるだけにする。
- **「選手に言う言葉」「コーチが見るところ」「できている形」「なぜそうなるか」は分けて書く。** 混ぜると現場で使えない。
- **「原典の説明」の引用だけは、本の言葉をそのまま残す**（「ボトムハンド＝引き手」「トップハンド＝押し手」「骨盤＝腰」「ヘッド＝バットの先」）。後で本と照らし合わせるため。**選手やコーチに渡す最終資料には、引用をそのまま載せない。**

## 1. 全体の組み立て — なぜこの5本なのか

**5本はフラットに並んでいるのではなく、下に土台があり、その上に4つが載る。**

```
                  ┌──────────────┐
                  │  基礎の体操   │  腰を止めて、上だけ回せるようにする
                  │  (p054-057)  │  ← 体重移動と割れの両方の土台
                  └──────┬───────┘
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   ① 体重移動        ④ 割れ         ③ トップ      ② 引き手の肩のリード
   (p066-069)     (p135-139)     (p154-157)      (p072-085)
   土台の能力を     着地の瞬間に     踏み出しと      ボールのコースと
   一歩の移動と     グリップが       グリップを      高さに、肩と腕の
   着地に載せる     捕手側に         引く動きを      ラインを合わせる
                   残っている形     合わせる        （置きティー）
```

**この構造は原典が自分で説明している。** p056-057 にこうある。

> それら（胸から腰までの上体・肩甲骨・背骨）が動けば、**腰も顔も動かさずに上体だけを回すことができる**のです。ですから、バッティングで「頭を動かさずに軸回転で打つ」などと言われる動作は、ステップで前に進んでから着地後、これらの関節が十分に動くことによって、**後ろ腰が前に進みながらも、その腰の動きの影響を受けずに、上体が背骨を軸に回転して両肩が入れ替わって実現している**のであり、**いくら「頭を固定しろ」と言っても、これらの関節の動きが悪ければ不可能なのです。**

つまり原典は、基礎の体操で作る能力を、**「後ろ腰が前に進む（＝体重移動）」と「腰の動きに引きずられずに上体だけが回る」の両方の前提条件**として説明している。だから基礎は準備運動ではなく、土台として1本を使う。

> **注意：「上体が回ること」は割れではない。** 割れは④で扱う別のもの（→【④】の冒頭）。基礎の体操が土台になるのは、**割れをつくるにも、体重移動をするにも、「腰と上体が別々に動ける」ことが先に要る**からであって、体操そのものが割れをつくるわけではない。

そして原典は、この土台が何を生むかも書いている。

> 上体の回転動作でバットが引き出されることによって、バットは「トップ」でのトップハンドの肩先との近い位置関係が変わらずに前に運ばれます。**これがバットを「内から出す」というスイング始動の仕組みです。**……脊柱を軸に両肩が入れ替わる上体の回転動作と、……後ろ腰が直線的に進んで向きが変わる骨盤の回転動作との組み合わせによって、**バットを「内から」素早く無駄なく前に運ぶスイングが実現するのです。**（p056-057）

**＝ 強く振れて、しかも最短距離でボールに届く。** これが5本すべての行き先。

### ③トップと④割れは、原典では「同じ瞬間」

原典はこの2つを分けていない。

> **「トップ」での体幹の「割れ」**をつくる動きを覚えるのにも非常に効果的（p120-121）
> 着地寸前までにテイクバックの動きが完了して**「割れ」もできあがっている**（p138）

**テイクバックが終わった状態を「形」で呼べばトップ、「張力」で呼べば割れ。同じ瞬間のこと。**

**コーチが「トップの練習」と「割れの練習」を別物だと思って別々に教えると、かえって伝わりにくくなる。** ③と④は、**同じ瞬間を上半身側から入るか、下半身側から入るかの違い**として扱う。

## 3. 要素に分解して照合し、厳選する

**ドリルの名前を突き合わせても意味がない。** 原典は40近いドリルを写真と手順と狙いつきで載せている。**その動作要素を、成人向け指導・バイオメカニクス・医学・少年向けの注意と照合して、どれが最適かを決める。**

### 3-1 外部資料が実際に語っている9つの要素

外部資料が「何かを言っている」動作要素は、次の9つに整理できる。**この9つが照合の物差しになる。**

| | 要素 | 外部資料が言っていること |
|---|---|---|
| **A** | **踏み出し足の接地**（安定・再現性） | 接地が連鎖の節目（Welch）／踏み出し脚側の水平の地面反力が体幹のエネルギーの流れと関係する（Horiuchi）／**痛みを伴う反復着地・不安定な着地・膝の内側崩れを続けない**（医学）／短く柔らかい踏み出し（Cal Ripken）／**大きく跳ねる・早く前へ出るは失敗例**（Step Backs） |
| **B** | **腰が軸足側に残り切らない／頭・上体だけ突っ込まない** | 後方への準備→接地→腰・上体・腕の連鎖（Welch）／**少年と成人では踏み出し脚の動きも腰・上体の向きも違う**（Escamilla）／**前の脚の強い固定・大きな後ろ乗りは持ち込まない** |
| **C** | **腰と上体の時間差を、角度ではなく時間で扱う** | **年齢で相対的なずれが変わる＝角度を求めない**（Tsutsui）／分離は強い逆ひねりでなく制約で作る（Driveline）／**腰の反り・回しすぎ・横崩れの代償を反復させない。若年の腰椎分離症**（医学） |
| **D** | **上体そのものの回旋（胸から腰までの上体・肩甲骨・背骨）** | 腰→上体→腕→バットの順に速さが乗る（運動連鎖）。**ただし「これだけを単体で鍛えるドリル」は外部資料に見当たらない。** 逆に**「腰を完全固定して上体だけを強く回す」は代償が集中する**と医学側が警告 |
| **E** | **上体→肩→腕→バットの連続（手・腕だけ先行させない）** | **振り始めに手が体から早く離れるのを抑える**（MLB Connection Ball）／腕も連続動作に含まれる（Welch）／**肩だけを強く引く・出すは首・肩まわり・腰の代償**（医学） |
| **F** | **バットの通り道（面・方向・高さ）** | バットの深さ・方向性・上からかぶせる動きを見る（Offset Open）／ティーでバットの通り道を確認する（Little League） |
| **G** | **準備（グリップを引く動き）と踏み出しの時間関係** | ロードとストライドのタイミング（Driveline／Little League）／**グリップを背中側へ引き続けると肩・首が張る。着地後も手だけで引き続けるのは遅れ**（医学） |
| **H** | **姿勢の維持（脚のつけ根で支える・腰を反らない）** | 姿勢は腰の反りや曲げで作らず**股関節で支える**（Driveline hip hinge／spine angle）／腰椎の代償を避ける（医学） |
| **I** | **置きティーから、投げられた球への転移** | **ティーと投げられた球では上体の動きが同じにならない**（Bordelon） |

**要素になっていないもの**：割れの角度、後ろに乗せる割合、回転の速さ、バットの速さ——**外部資料はどれも「少年に目標として与えるな」と言っている側**。だから照合の物差しにしない。

# ■ 基礎 ─ 腰を止めて、上だけ回す体操

**原典**: p054-057「上体の回転動作の動きづくりの体操」
**検証**: 400dpiで本文を確認済み

## 何のためにやるか

**腰（骨盤）を正面に向けたまま、胸から上だけを回せるようにする。**

これができないと、①体重移動も④割れも作れない。逆にこれができれば、その先は自然につながる。**この5本の中で、いちばん最初に、いちばん確実にできるようにしたい動き。**

## どういう効果があるか

**いちばんの効果はこれ。**

> **バットを速く振るための回転が、腕ではなく胴体から出るようになる。**
> **背骨を軸にした、素早い回転。**

腕を速く振ろうとしても速くならない。速さは胴体の回転から出る。**その回転を作るための体操。**

原典は、その回転が何を生むかまで書いている。

> 上体の回転動作でバットが引き出されることによって、バットは「トップ」でのトップハンドの肩先との近い位置関係が変わらずに前に運ばれます。これが**バットを「内から出す」**というスイング始動の仕組みです。（p056-057）

**＝ 強く振れて、しかもバットが遠回りしない。**

**あわせて起きること**

- 腰と上体が別々に動けるようになる（①体重移動と④割れの、両方の前提）
- 打つときに頭が流れなくなる。**「頭を固定しろ」と言っても直らないものが、ここで直る**（p056-057）
- **④で直そうとしている「着地で踏み出し脚の膝が内へ入る」の根本原因が、ここにある。** 原典 p141 は、その原因を「**肩甲骨や胸郭の動きが悪い**」「**脚のつけ根を引き込めず、膝で沈む**」とし、**「そうした関節の動きの改善を並行して進める必要がある」**と書いている。**この体操が、まさにその2つを扱っている**（悪い例 写真3-6「膝が前に出ている」がそれ）。**ただしこの記述は、膝が内に入る選手についての記述であって、「全員が④をやるべき」の根拠ではない**（2026-09-12 訂正）

> **この体操の「腰を止める」は、体操の中だけの決まりごと。** 上体だけを動かす感覚をつかむためのもので、**実際に打つときに腰を止めるという意味ではない**（原典 p188、外部調査 §4-2。→ §3-1）。

## やり方

1. 肩幅より少し広めに立ち、**腰をわずかに落とす**
2. **両手を肩に置き、両肘を胴体につける。** 両腕を胴体に密着させ、**肩を前へすぼめる**
3. **腰は正面に向けたまま**、片方の肩が**真正面のあごの下**にくるように、**胸から上だけを水平に回す**
4. 左右交互にくり返す

**進め方は3段階（原典が指定）**

| 段階 | やり方 |
|---|---|
| 1 | **1回ずつ止めながら。** どこまで回るか、どう動くかを確かめる |
| 2 | 止めずに、リズムよく |
| 3 | **全速力でくり返す** |

**腰の落とし方**：膝をあまり前に出さず、**脚のつけ根を引き込むようにして軽く沈む**。上体は立てたまま。

**腕をこの形にする理由**（原典 p054）：胴体と腕を一体にして、**胴体だけの動きで上体を回す**ため。また、**回る半径をいちばん小さくして回りやすくする**ため。

## 選手に言う言葉（1回に1つだけ）

- 「腰は正面のまま、上だけ回す」
- 「肩をあごの下まで」

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 腰が一緒に回っていないか／顔が一緒に回っていないか |
| **横** | 膝が前に出て沈んでいないか／上体が前に倒れていないか／腕が胴体から離れていないか |

## できている形

腰と顔は正面のまま、肩だけがあごの下に入ってくる。

## よくある崩れ方（原典が写真番号つきで挙げている5つ）

| | 崩れ方 | どう見えるか |
|---|---|---|
| 写真3-6 | **膝が前に出ている** | 脚のつけ根ではなく膝で沈んでいる。**原典が「非常に多い」としている** |
| 写真3-7 | **上体が前に倒れている** | つけ根の引き込みを強調しすぎた結果 |
| 写真3-8 | **腕が構えの位置から離れている** | 肘が胴体から浮く |
| 写真3-9 | **膝が動いて腰も一緒に回っている** | 下半身が止まっていない |
| 写真3-10 | **腰・上体・顔がひとかたまりで向きを変えている** | 3-9をさらに極端にした形 |
| （番号未確認） | **肩があごの前に上がってしまう** | 肩がすくむ |

**崩れる理由は「やる気」ではなく体の動き。** 原典はこう説明している。

> これは、上体の回転をつくっている**胸から腰までの上体・肩甲骨・背骨**——一つ一つが動かないことによるもの

**だから、できない選手を責めない。** ここは「今どこまで動くか」を測る枠でもある。

## 安全のために

- 反動で強くひねらせない。**回る大きさを競わせない**
- 痛みや違和感が出たら中止
- 第3段階（全速力）は、第1・第2段階の形が保てている選手だけ

## 簡単にする方法・変える方法

- **腰が一緒に回ってしまう選手**：椅子に座って行う、または膝立ちで行う（原典 p052-053 に膝立ちの形がある）
- **変形（原典 写真3-11）**：腕を左右に開いた形でも行える。ただし**胸を張るように引き分けるのではなく**、真横よりやや前を向いた向きで、肘を楽に落とす

## 原典の説明（要点）

> 肩幅より少し広めのスタンスで腰をわずかに落として立ち、両手を肩に、両肘を胴体に付け、その両腕を密着させて肩をすぼめて構えます。そして、骨盤はなるべく正面に向けたまま、一方の肩が真正面のあごの下にくるように、上体だけを水平に回転させる動きを左右交互に繰り返します（写真3-4）。最初のうちは、可動域と動き方を確認するように1回ずつ止めながら行い、次第にリズミカルにして、最後は全速力で反復します。（p054）

| 反動をつけて強くひねる | 腰を反る・横へ崩れる | **反動を使わない。** 止めて回す段階から始める |

| 回る大きさを競わせる | 可動域を押し込む | **どこまで回るかを比べさせない。** 今どこまで動くかを見るだけ |

# ■ ① 体重移動 ─ 一歩ステップと腰・上体の回転

**原典**: p066-069「上体の回転動作と骨盤の回転動作の組み合わせの体操」
**検証**: p066の本文を400dpiで確認済み。p067-069は未検証

## 何のためにやるか

**基礎の体操で作った「腰を止めて上だけ回す」能力を、一歩の移動と着地に載せる。**

打撃で言う体重移動とは、原典では**「腰を横向きに近いまま、踏み出す足の方向へ運ぶ動き」**のこと。「後ろに乗ってから前に移す」ことではない。

## どういう効果があるか

- 後ろに体重が残ったまま腕だけで振る、がなくなる
- 頭から突っ込む、がなくなる
- **着地の瞬間に、腰の移動と両肩の入れ替えが重なって起きる**——その重なりが身につく

## やり方

1. 肩幅くらいに立つ。**腰はほとんど沈めない**
2. 顔だけ投手方向へ向ける
3. **真横にただ一歩踏み出す**
4. その一歩に合わせて、**引き手（右打者なら左手）の肩をあごの下へ引き寄せる**
5. **左足が着いた瞬間に**、腰を横向きのまま左足の方向へ運びながら回し、**同時に両肩を一瞬で入れ替える**

**バットは持たない。全員同時にできる。**

**腕の構えは2通りある**（原典 p066 の「2つの体勢どちらか」、写真3-17〜3-20）。

| | 構え |
|---|---|
| **A** | **両肩をすぼめて**（基礎の体操と同じ構え） |
| **B** | **腕を肩の横で固定して** |

**どちらでもよい。** 基礎の体操からそのままつなげるなら A。

## 選手に言う言葉（1回に1つだけ）

- 「左足を静かに置く」
- 「頭だけ先に行かない」
- 「左足が着く瞬間、肩を入れ替える」

> **【訂正 2026-09-12】** 前版は「左足が着いたら、その場で回る」としていたが、**原典 p066 と逆。** 原典は「**着地した瞬間に**、下半身では……上半身では……**同時に行います**」と書いている。**「着いてから回る」ではなく「着く瞬間に重なって起きる」。**

## 言ってはいけない言葉

「体重を全部前へ乗せろ」／「強く踏み込め」／「腰を先に切れ」／「前の脚を伸ばして固めろ」／**「後ろに乗れ」**／「壁を作れ」

> **「後ろに乗れ」がなぜ駄目か**：原典 p132 は、**軸足に体重を残してしまうことを、この年代で最も多い勘違い**として名指ししている。「後ろに乗れ」と言うと、そのまま後ろに残る。**見るのは「後ろに乗れているか」ではなく「後ろに残っていないか」。**

> **「腰を先に切れ」がなぜ駄目か**：原典 p123 は、**腰が横へ運ばれる動き（スライド動作）がないと、腰は逆回りにしか回れない**と書いている。先に回そうとすると、**進みながら回ることができなくなる。**

> **「壁を作れ」がなぜ駄目か**：現場でよく使われるが、**何をすれば壁になるのかが伝わらない。** 原典 p123 によれば「壁」とは、**後ろ腰が直線的に前へ進み、回転の支点が踏み出し脚に移ったときに得られる感覚**のこと。**結果であって、やることではない。** コーチが理解するための言葉として用語集に入れてある。

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 頭と胸が左足より先に大きく倒れ込んでいないか／左膝が内側へ崩れていないか |
| **横（三塁側）** | **右腰が右足の側に置き去りになっていないか**（最重要）／左足が跳ねず毎回近い位置に静かに着くか／左足がつま先だけで不安定になっていないか／左脚を早く固めていないか |
| **横（腰の代わりに、軸足を見る）** | **右足がどう返っているか。** 横向きに返って**親指の内側で地面を支える**形を通っていれば、腰は直進している |

> **腰の中は見えない。でも足は見える。** 原典 p124 はこう書いている——「**軸足は骨盤の動きに引っ張られて返るものなので、その返り方は、骨盤の動きを映す鏡なのです**」。**野球経験のないコーチにとって、いちばん判定しやすい観察点。**

## できている形

**左足が着く瞬間、後ろ腰を少し前へ運びながら、両肩を入れ替えている。**（原典 p066）

左足に飛び込むのでもなく、着いてから回るのでもない。**重なって起きる。**

> **【訂正 2026-09-12】** 前版は「左足の上で一瞬止まれて、そのあと回れる」を**できている形**に置いていた。これは Perplexity の表現で、**原典 p066「同時に行います」と矛盾する。**
> **一度止まる形は、簡略化した練習としては使ってよい**（簡単にする方法を参照）。**ただし完成形にはしない。**

> **コーチが1回に言うのは1つだけ。** 上の一文は**コーチが理解するための形**であって、そのまま選手に言う言葉ではない。選手には「左足を静かに置く」か「肩を入れ替える」のどちらか一方を言う。

**もうひとつ、目で見て分かる形がある。**

> 横から見て、**踏み出した足元から頭までが、斜めの一直線**になっている。原典はこれを「**ステイバックライン**」と呼んでいる（p123）。**腰が踏み出し脚へ進まないと、この形はできない。**

## よくある崩れ方

1. **軸足に体重が残って腰が前へ進まない**（原典が最多とする）
2. 頭が横に流れる
3. 着地で左膝が内側に入る
4. 大きく跳ねる
5. 前に傾いたまま準備に入る

## 安全のために

一歩の幅を大きくさせない。バットを持たせない。前後左右の間隔は、実際に動かせてから決める（「2m」は目安であって安全の保証ではない）。

### やりすぎると何が起きるか（外部調査より）

| 大人の指導でよくある強め方 | 小学生で起きうること | **ここまで** | **やめる合図** |
|---|---|---|---|
| 前の脚を強く止める／最初から伸ばして固める | 膝が内へ崩れる、着地が不安定、痛みを我慢して繰り返す | **踏み出し足が痛みなく着き、膝が足の上で支えられ、そのあと回れる**程度 | 膝・足首・股関節の痛み、膝が内へ大きく崩れる、ふらつきが続く |
| 腰だけを早く強く回す | 上体・腕とのつながりが切れる、姿勢が崩れる、腰が反る | 腰の移動と回転を、**上体・肩・腕の続きの一部として小さく**扱う | 腰が反る、頭が大きく流れる、上体が前後に崩れる |
| 大きく踏み出す、跳ねて踏み出す | 毎回着地点がばらつく、前へ突っ込む | **自然な範囲の小さな一歩。安定して着地できる大きさ** | 着地点が大きくばらつく、体ごと前へ飛ぶ、つま先だけで不安定 |

**持ち込まないもの**：大人の角度・速度・力の目標値／前の脚の強い固定／大きな後ろ乗り／強い前方への爆発／道具を使う発展形

## 簡単にする方法

一歩置いたところで**一度止める**。着地の形だけ確かめる。

## 原典の説明（要点）

> まず、肩幅程度のスタンスで重心はほとんど沈めずに立ち、上体は……2つの体勢どちらかで構え、顔だけを投手方向に向けておきます。そこから、**真横にただ一歩踏み出すだけのステップに合わせて、ボトムハンドの肩をあごの下に引き寄せ**、**着地した瞬間に、下半身では骨盤を横向きに近い状態のまま踏み出し脚方向に移動させる「スライド動作」から始まる回転動作**を、上半身では**両肩を一瞬で入れ替える回転動作**を、同時に行います。（p066）

# ■ ② 引き手の肩によるスイングの始動 ─ 左右対称スイング＋置きティー

**原典**: p072-085
**検証**: p072の本文を400dpiで確認済み。p073-085は一部未検証

## 何のためにやるか

**ボールが来るコース（方向）と高さに、引き手の肩から腕までのラインを合わせていく。** これが「引き手の肩でリードする」ことの目的。

原典は、着地でできるトップの形について、こう書いている。

> **ボトムハンドの腕からバットのラインが、高めの球へのスイングプレーンと一致していることが大切です**（p157）

つまり、**肩と腕のラインが、その球を打つ面と同じ向きになっている**こと。ここが合っていないと、どれだけ振ろうとしてもバットはその面に乗らない。だから置きティーは**高めから始めて、できるようになったら次第に低くする**（p106）。**高さを変えて、そのつど合わせ直す練習**になっている。

**そして、基礎の体操で作った胴体の回転とかみ合ったとき、強いスイングになり、しかもバットが最短距離でボールに届く**（p056-057「バットを『内から』素早く無駄なく前に運ぶ」）。

**バットを、腕ではなく引き手の肩から動かし始める**のはそのため。原典は「押し手（右打者なら右手）に意識を持たせるのはマイナスにしかならない」（p018）としている。

## どういう効果があるか

- 引き手の肩から腕のラインが、球の高さ・コースに合うようになる
- 手だけでバットを放り出す（腕が先に体から離れる）がなくなる
- バットが遠回りしなくなる（最短距離でボールに届く）
- 手首を返そうとしなくなる（返そうとしなくても返る）

**原典がこのドリルの意味として挙げている2点**（p082-083）

1. **引き手の肩がバットを引き出すこと**
2. 振り出す方向を前へ移し、スイング全体の円い軌道をフォロースルー側へずらすことで、**引き手の肩のリードを強制的に生み出すこと**

## やり方

1. **立てたバットの真上に頭がくるように立つ**
2. 踏み出す脚が前。**その脚に全体重を乗せる。** 後ろの脚はバランスのため、つま先を床に触れさせておくだけ
3. **引き手1本**でバットを握る
4. バットを立てていた位置（頭の真下）を中心に、**振り子のように左右へ揺らす**
5. **バットの先の動きが、つま先の向いている正面方向に対して、きっちり直角になるようにする**
6. そこから実際に振る

### 「小さく前ならえ」の空間 ─ この年代に最も伝わる目印（原典 p181-184）

**原典は、スイングの本質をこう説明している。**

| | 押し手の肘とグリップはどこにあるか |
|---|---|
| **トップ（振り出す前）** | 胴体の前で**「小さく前ならえ」をしたときに腕で囲まれる空間の、外側** |
| **インパクト（当たるとき）** | **コースにかかわらず、その空間の中に入ってくる** |

> **バットを素早く前に出すとは、この「外から中へ」を、いかに素早くやるかということ。**

**そして、そのやり方を原典は名指しで否定している。**

> それには、**押し手の肘をあごの前に入れてくるといったことではなく**、肩甲骨・胸から腰までの上体（胸郭）がよく動いて、背骨がよく回り、**両肩をあごの下のところで入れ替える上体の回転動作が、十分に動くことが大切**なのです（p183）

> **引き手の肩があごの下に入っていってはじめて、上体の回転でバットを引き出すことができ、その上体の回転により、押し手の肘は胴体前面に素早く入り込んでくれる**のです（p184）

**順番が決まっている。** 引き手の肩があごの下へ → 上体が回る → **その結果として**押し手の肘が体の前に入る。**押し手の肘を入れに行くのではない。**

> **コーチが見るときの目印にできる。** 「小さく前ならえ」は子どもに説明しなくても通じる。**当たるところで、両肘がその空間の中に入ってきているか。**

### なぜ最初は「真下」に振るのか（原典 p079 が2つ挙げている）

1. **左右対称の軌道かどうかを確認しやすい**
2. **重力を利用して真下にバットを落とせば、肩まわりの筋力が弱くても、引き手の肩のリードの動きが引き出せる**

> **このドリルが小学生に向く理由がここにある。力がなくてもできる。強く振る必要がない。**

**原典は、第8章の「振り子ドリル」でも同じ原理を説明している。**

> なぜ「振り子ドリル」は下向きにスイングするのかというと、**重力を利用して肩甲骨外転の動き（肩をすぼませる動き）を引き出すため**です（p179）

**「真下に振る」＝「重力で、肩をすぼめる動きを引き出す」。** ②と第8章で同じことを言っている。**そして「肩をすぼめる」は基礎の体操の構えそのもの。**

**原典の段階は STEP1〜6 まである**（2026-09-12 に STEP4・STEP5 の存在を確認。**前版は STEP4・5 を丸ごと落としていた**）。

| 段階 | 内容 | 原典 |
|---|---|---|
| STEP1 | **片手・真下** | p072-077 |
| STEP2 | **両手・真下** | p078 |
| STEP3 | **両手・正面・ベルトの高さ** | p079 |
| **STEP4** | **踏み出し＋STEP3**（一歩の踏み出しから、ベルトの高さへ左右対称に振る） | **p082-083** |
| **STEP5** | **横向き＋STEP4**（実際の打席に近い横向きの体勢から踏み出して、同じスイング） | **p084** |
| STEP6 | **置きティー** | p085 |

> **原典 STEP4（p083）**：「STEP3でベルトの高さに左右対称のスイングができたならば、**同じスイングを一歩の踏み出し動作から行います**」
> **原典 STEP5（p084）**：「一歩のステップを加えても左右対称のスイングができたならば、今度は、**横向きの体勢から踏み出しても同じスイングができるように**します」。ここで特に大切なのは「**骨盤の向きをスタートと同じに投手方向に対して真横の状態のまま、一切変えずにステップすること**」

>
> **厳選としては逆。** 真下に振るのは**肩まわりの筋力が弱くても肩のリードを引き出すための仕掛け**（p079）であって、完成形ではない。

**崩れたら、その場で段階を下げる。**

**使うバット**：原典は年代別に指定している。**小学生はプラスチックバット。** 中学生は小学校低学年用バット、高校生はノックバットを短く持つ。一度できるようになれば通常のバットでよい。

## 置きティー（1人5球×1巡）

- **打ちごろの位置に置かない。** 作ったスイングが**そのまま出せる位置**に置く（p085）
- **高めから始めて、できるようになったら次第に低くする**（p106）
- **ストライクゾーンを打つ練習ではない。** 原典は「ストライクゾーンの球を打つことにこだわっていては何も変わらない」としている（p082）

## 選手に言う言葉（1回に1つだけ）

- 「肩から先に動かす」
- 「手だけでバットを放り出さない」
- 「返そうとしない。勝手に返る」

## 言ってはいけない言葉

「前の肩を強く引け」／「押し手で押し込め」（原典 p018）／「手首を返せ」／「フォロースルーを大きく」（原典 p092：原因が変わらなければ大きくならない）／**「顔を投手に正対させて両目で見ろ」**

> **「顔を正対させて両目で見ろ」を、原典は否定している**（p128-129 のコラム）。構えで顔を投手に正対させると、**打つまでに必ず顔の向きが動いてしまう。** インパクトのときの顔の向きのまま構えれば、**眼球の動きだけで球を追える**——これが最も無駄がなく正確だ、としている。
> **したがって「顔を正面に向けろ」とは言わない。** ①の体操で「顔だけ投手方向へ」と言うのは、**上体の回転だけを取り出すためのドリルの決まりごと**であって、打席での構えの指示ではない。

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面または真後ろ** | 左右対称に振れているか（**一目で分かる**）／打つときに顔が早く三塁側を向いてボールから目が切れていないか |
| **正面（当たるところで）** | **両肘が、「小さく前ならえ」で腕に囲まれる空間の中に入ってきているか**（原典 p182-183） |
| **横（真横から）** | **引き手の肩→腕→バットのラインが、前下がりで、左右の傾きがない面の上を、終始動いているか**（原典 p078、写真4-7）／腕とバットだけが先に体から離れていないか／右肩だけが落ちたり前へ突っ込んだりしていないか |

## できている形

# ■ ③ トップの作り方 ─ テイクバックの動きづくり（STEP1〜5）

**原典**: **p154-165**「4. 上半身と下半身のリズムを合わせるテイクバックの動きづくり」＋ p166-167（グリップの上下動の幅）

> **前の版からの変更**：前の版では p144-147 を挙げていたが、**p154-157 の STEP1〜3 のほうが、子どもには分かりやすい。** 手順が3段階に切ってあり、着地でできるトップの形が「どうなっていれば正しいか」まで書いてあるため。**ドリル名の「①」は外した**（①しかないので番号に意味がない）。

## 何のためにやるか

**踏み出す動きと、グリップを引く動きの、リズムを合わせる。**

原典はこう書いている。

> **「トップ」の体勢さえ身体で覚えれば、テイクバック動作は、どんな構え方からでもその「トップ」の体勢に移行してくればいいだけです**（p154）

つまり**構えは自由**。直しに行くのは構えではなく、**踏み出しとグリップのタイミング**。

## どういう効果があるか

- 手だけを後ろに引く、がなくなる
- 着地したときに、**引き手の腕からバットのラインが、打つ球の面と合っている**状態ができる
- **形を指示しなくてもトップが決まる。** バットを肩に乗せた構えでは、バットの先は自然に頭の後ろ、押し手の肘は自然に下向きになる

## やり方 ─ 3段階

**STEP1（その場、上半身だけ）**

> バットを真横に寝かせて肩に乗せて構え、そこからバットは肩に乗せたまま、**バットが45度くらいになるまでグリップを降ろし、再び元の位置に戻す**動作を繰り返す（p155）

**STEP2（脚を足す）**

> **グリップを降ろす動きに合わせて軸足に体重を乗せ**、**踏み出しに合わせてグリップを元の位置に戻す**（p156）
>
> このときの脚の動きは**「すり足」でも「一本足」でもどちらでも構わない**（p156）

**STEP3（進んだ分だけバットを外す）**

> STEP2と同じように軸足に体重を乗せる動きから、踏み出しに合わせてグリップを元の位置に戻すときに、**空間的に元の位置へ戻すように、踏み出しで進んだ分だけバットを肩から外す**（p156-157）

**STEP4（球の高さに合わせる）** ← **2026-09-11 追加。読み落としていた**

> STEP3のテイクバック動作から、**振る高さを変えて素振りやティーバッティングをし**、この一連の動きの意味を身体で理解する。
> **高めの球なら、STEP3のテイクバックは全く変えずにグリップを引く。低めの球なら、グリップを下げたところからそのままグリップを引いて、「トップ」での引き手からバットにかけてのラインの角度を、低めの球に向かうスイングプレーンに合わせてスイングする**（p158-159）

**STEP5（構えを変えても同じテイクバック）** ← **今回の練習では使わない。知っておくだけ**

> 肩に乗せて構えていたバットを肩から浮かせ、寝かせた構えから STEP3 と同じことをする。**構えの位置は上がっても「トップ」の体勢はこれまでと同じ。** さらに、**バットを立てた構えからでも同じ動きができる**（p162-163）

**これが原典の「構えは自由」の根拠。** 脚を上げる前にはどちらもほぼ同じ体勢になり、軸足に体重を乗せてグリップを下げた体勢からは**全く同じ動き**になる。

**STEP3が形、STEP4が使い方。** STEP1・STEP2 はそこへ行くための段取り。

# ■ ④ 割れ ─ 割れをつくるステップ

**原典**: p135-139（量の上限は p038、タイミングは p137、変形は p140-141）
**検証**: p135の本文を400dpiで確認済み。p136-139は一部未検証

> **このドリルは、汎用的なドリルとして残す**（オーナー判断 2026-09-12）。
> ただし原典はこのドリルを**「特に、着地時にどうしても踏み出し脚の膝が内に向いてしまって、上半身との間に十分な割れをつくれない選手のためのドリル」**と、対象を限定して紹介している（p135）。他の4本には限定がない。
> **したがって「原典では対象を限定して紹介されているドリルである」ことは、資料に必ず明記する**（下記「このドリルの位置づけ」）。

## 「割れ」とは何か ─ ここを取り違えない

**「上体が回ること」は割れではない。**

割れとは、**踏み出した足が地面に着いた瞬間に、グリップが体の外側（捕手の側）に残っていて、上と下が反対方向へ行こうとしているために、筋肉と関節が引き伸ばされている状態**のこと。

- **下**（腰・体重）は**投手方向へ進んでいる**
- **上**（グリップ・引き手の肩）は**捕手方向に残っている**
- その**反対向き**が、筋肉と関節を伸ばす

原典は「割れ」を一文で定義していないが、同じ意味の記述が3か所に分かれている。

| 原典 | 記述 | 何を言っているか |
|---|---|---|
| 第5章（BOXスイング） | **体重を前に進めながらテイクバックを行って**、そこからスイングを開始します。……この移行動作は、**「トップ」での体幹の「割れ」をつくる動きを覚えるのにも非常に効果的です** | **上と下が反対向き**。これが割れを生む |
| p137 | **引き手（ボトムハンド）を捕手方向に引くテイクバックの動きは、着地寸前の時点で終わっています**／着地寸前で「割れ」をつくります | **着地の瞬間に、グリップは捕手側にある** |
| p084 | 着地時に、**骨盤の向きに対して引き手の肩が入ったスイング始動の準備態勢** | 腰の向きに対して、肩のほうが遅れている |

> **用語集の訂正**：`batting-glossary.md` は「割れ＝ボトムハンド側の肩のストレッチ状態（p084）」としているが、**このページ番号は誤り。** 「ストレッチ」という語が出るのは第3章 STEP3（p060-061）の「テイクバックでのボトムハンドの肩のストレッチ」。用語集を直す必要がある。

**角度でも、大きさでもない。**

## 何のためにやるか

**このドリルで全員に教えたいのは、角度ではなく時間。**

> **踏み出した足が着く寸前までに、グリップを引く動きが終わっている**（p137）

基礎の体操で作った「腰を止めて上だけ回す」能力を、**打撃に近い下半身の条件の中で出す**。

## なぜこれが最も重要か ─ 打つか見送るかを決められるようになる

**着地の寸前にグリップを引き終わっている、ということは、その時点で「トップ」ができあがっていて、割れもできている、ということ。**

**つまり、着地した時点で、いつでも振り出せる状態になっている。** だから、そこから**打つか、見送るかを決められる**（スイングデシジョン＝選球）。

逆に、着地してからまだグリップを引いているようだと、**振ると決めてからでないと間に合わない。** 見て選ぶ余裕が減る。

> **【訂正 2026-09-12】** 前版は「『振り遅れる』『手を出してしまう』『見逃せない』の正体はここにある」と**効果を断定していた。** 言い過ぎ。
> **「準備が着地までに終われば、判断する時間を確保しやすい」という仮説にとどめる。** 実際にそうなるかは、**通常のトスや実戦打撃で別途確かめる転移の目標**として置く。

> **これは原典に書かれていない。** 打撃指導の世界で広く言われている考え方（定説）として扱う。**研究で確かめた話ではない。**
> ただし、原典が「着地寸前に引き終わっている」を条件として明示していることと、方向は一致している。

## 着地のあと、何が起きるか（原典 p138。2026-09-11 に確認）

**原典は、割れを「作る」だけでなく「戻す」ところまで書いている。**

> **着地寸前までにテイクバックの動きが完了して「割れ」もできあがっているからこそ、完全着地を合図に「割れ」を戻して、上体の回転によるスイングのリードを開始できるのです**（p138）

**完全に足が着いたときが合図。** そこから割れが戻り、上体の回転でスイングが始まる。**「着地寸前に引き終える」は、この合図を成立させるための条件だった。**

## どういう効果があるか

- **着地した時点で、打つ／見送るを選べるようになる**（上記）
- **完全着地を合図にスイングを始められる**（上記）
- 着地してからグリップを引き始める、がなくなる
- 腰だけが早く開く、がなくなる
- 踏み出す足の膝が内側に入る選手に、特に効く

> **「両膝の向きを固定する」は、割れを感じさせるための一時的な条件。** 打撃で腰を固定しろという意味ではない（→ §3-3）。**外部調査が「少年へ持ち込まない」としているのは、目標としての骨盤固定のほう。**

### このドリルの位置づけ（2026-09-12 決定）

## やり方

1. **両足をつけて立ち、脚のつけ根を後ろに引き込みながら軽く膝を曲げて構える**
2. **両膝だけを、投球が来る方向へ向きを変える**
3. その膝の向きを固定しておくつもりで、**上半身を、膝と逆の45度方向へわずかにかぶせる**
4. そこから一歩踏み出し、**着地で割れをつくる**

**前半はバットなし。後半だけバットを持つ。**

## 量の上限（守る）

> 上体は本来あまり深く捻らなくてよい。**引き手側の肩を引き寄せるくらい**の方が効果的（原典 p038）

**大きくする方向へ持っていかない。選手どうしで大きさを比べさせない。**

## 選手に言う言葉（1回に1つだけ）

- 「左足が着く前に、グリップを引こう」
- 「左足が着いたら、引くのはおしまい」

## 言ってはいけない言葉

「胸を強くねじれ」／「腰を開いてから上体を回せ」／**「割れを大きく」**／「上体を大きく三塁側へ向けろ」

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 腰や膝まで一緒に動いていないか／左足が着くときに胸と両肩が投手方向へ開き切っていないか |
| **横** | 左足が着く寸前にグリップを引き終わっているか／**腰が反っていないか**／上体が前に折れていないか |

## できている形

左足が着いた瞬間に、グリップの動きがすでに止まっている。腰は反っても折れてもいない。

## よくある崩れ方

1. 膝と一緒に腰まで回る
2. **腰が反る**
3. 肩がすくむ
4. グリップを引き終わるのが着地より遅れる
5. 大きくしようとしてねじる

## 安全のために ─ 5本の中で最も注意が要る

- **腰が反ったら、その場で止めて、バットなしの形の確認に戻す**
- 動きの大きさ、着地の幅を競わせない
- **腰痛・背中の痛み・しびれが出たら、その日の回旋と打撃の練習をやめて、保護者と医療の専門職へ相談する**
- 土日連続で行うので、回数を増やさない

### やりすぎると何が起きるか（外部調査より）

| 大人の指導でよくある強め方 | 小学生で起きうること | **ここまで** | **やめる合図** |
|---|---|---|---|
| **割れの大きさを競う、強く逆にねじる** | **腰を反る・回しすぎる・横へ崩れる**でごまかす、姿勢が崩れる | **角度を目的にしない。** 踏み出しとグリップを引く動きの**時間関係だけを、小さな動きで確認** | 腰痛、腰の反り、肩のすくみ、首の傾き、ふらつき |
| 腰を完全に止めて、上体だけを強く回す | 腰・肩まわり・首に負担が集中する | 腰も上体も**完全に止まるわけではない。** 続いた動きの中に時間差がある、と理解する | 腰が反る、膝・腰を無理に固める、痛みや違和感 |

**持ち込まないもの**：大きな分離の角度／上体の強い逆ひねり／腰を固定すること／道具／力や回転の速さを競う設定

> **腰の医学について。** 野球は腰を曲げる・反る・回す・横に倒す動きを繰り返す競技で、若い選手の腰痛の原因として**腰椎分離症**が報告されている。**ただしこれらの資料は、原典の低負荷ドリルが危険だと示すものではない。** 原典の「深くねじらなくてよい」（p038）という運用を**補強する**もの。

## 簡単にする方法・変える方法

- **簡単形**：バットなしで形の確認だけ
- **発展形（原典 p139、写真6-6）**：通常のスタンスから始め、**軸足に体重を乗せていく動きを加えて**同じステップを行う。このとき**軸足・腰・上体・顔・両腕・バットの関係は一切変えずに**踏み出し脚を引き寄せる
- **膝の向きが崩れる選手**：つま先の向きを変えた形（原典 p140-141）。**これは発展形ではなく、膝の向きを直すための修正**
  1. 構えは同じで、**踏み出し脚のつま先だけ30度くらい投手方向へ向ける**
  2. それができたら、**軸足のつま先だけを投手に対して横向きにして**、踏み出し脚のつま先と膝の向きをそのまま踏み出していく
  3. できたら発展形（p139）へ、最後は通常の向きに戻す

### 膝が内に入る「根本原因」を原典が名指ししている（p141）─ 最重要

> ステップで踏み出し脚の膝が内に入ってしまうのは、**肩甲骨や胸から腰までの上体（胸郭）の動きが悪く**、腰の向きと上体の向きを変えるのが苦手で、引き手の肩を十分に引き入れれば腰まで一緒に入ってしまうこと、**あるいは、脚のつけ根（股関節）を十分に引き込めず、膝の動きを中心に重心を沈めることしかできない**ことに根本原因があるので、**そうした関節の動きの改善を並行して進める必要があります**（p141）

**④で直そうとしている崩れの原因は、基礎の体操（p054-057）が扱っているものと同じ。**

- 「肩甲骨や胸郭の動きが悪い」→ **基礎の体操の目的そのもの**
- 「脚のつけ根を引き込めず、膝で沈む」→ **基礎の体操が写真3-6 で「膝が前に出ている」として名指ししている悪い例そのもの**

> **【訂正 2026-09-12】** 前版は、この p141 の「並行して進める必要がある」を**「だから④を全員がやるべき」の根拠**として使っていた。**これは読みすぎ。**
> p141 は「つま先の向きを変えるバリエーション」の節にある記述で、**その対象選手（膝が内に入る選手）について、根本原因も並行して直せ**と言っているにすぎない。**全員に行わせる根拠にはならない。**
> **④を全員が行うのは、原典の記述からではなく、ドリルとしての汎用性からの判断である**（このドリルの冒頭を参照）。

> **外部の補強**：子どもの運動学習をまとめた系統的レビューは、**身体の部位そのものより外側にある目標を指す言い方、実際に見せる説明、そして「毎回ではない」フィードバック**が役立つ可能性を示している（PLOS ONE 2022）。ただし**年齢も課題もばらばらで、どの言い方が常に最良とは言えない**。

## その日、全員に共通して見ることは3つまで

1. **後ろに残っていないか**
2. **踏み出す足を静かに置けているか。頭が先に行っていないか**
3. **着地のあと、胸の回転に肩・腕・バットがついてきているか**

## 中止・縮小の判断 ─ 5つの軸で見る

**回数では安全を判断しない。** 10〜12歳の打撃スイングについて、**1日・1週あたりの安全な上限を示す公的な基準は存在が確認できていない**（外部調査 §4-4）。投球には年齢別の球数の目安があるが、**投球の数字を打撃のスイング数に置き換えてはいけない**。

代わりに、次の5つで判断する。

| 見る軸 | 続けてよい | **その場で小さくする／やめる** |
|---|---|---|
| **痛み・違和感** | ない | **肩・肘・手首・腰・膝・足首・首に、痛み／しびれ／続く違和感** |
| **動きの質** | 着地・姿勢・バットの扱いが安定している | **腰が反る／膝が内へ崩れる／肩がすくむ／頭が大きく流れる／バットを扱いきれない、が続く** |
| **道具の扱い** | 安全に握って、止めて、振れる | **バットを落とす／振り終わりを止められない** |
| **目的** | 動きを確かめている | **速さ・飛距離・回数を競い始めた** |
| **見ていられるか** | コーチが誤りに気づいて、すぐ小さくできる | **人数や配置のせいで、見ていないところで強く振り続けている** |

**小さくする手順**：バットを軽くする → 動きを小さくする → バットを外して形だけにする → その日はやめる。

## 医学から言えること・言えないこと

**言えること**

- **腰**：腰を反らせて胸を残す、強くねじる、横へ崩れる——この代償を**反復させない**。**腰痛・背中の痛み・しびれ・繰り返し出る違和感があれば、その日の回旋・打撃練習を中止し、保護者と医療の専門職へ相談する**（若年野球選手の腰椎分離症の報告より）
- **腰の可動域を押し込むストレッチ、割れの大きさを競う練習は採らない**
- **膝**：**角度の数字では判断しない。** ①足・膝・股関節に痛みがない ②踏み出し足が繰り返しふらつかない ③膝が足の内側へ大きく落ち込み続けない ④動きを小さくすると安定が戻る——この4つで見る
- **成長期の練習は、監督下・技術優先・扱える道具・痛みのない範囲・段階的な負荷調整**（NSCA の立場）

**言えないこと（外部調査が「確認できなかった」と明記しているもの）**

- **10〜12歳の打撃スイングの、1日・1週あたりの安全な上限**
- **10〜12歳で、踏み出し脚の膝の内側への崩れを、故障や打撃成績に直接結びつけた研究**
- ここに挙げた5本のドリルのどれかが、10〜12歳の打撃を改善するという直接の研究

**これらの医学資料は、原典のドリルが危険だと示すものではない。** 原典の「深くねじらなくてよい」という運用を**補強する**もの。
