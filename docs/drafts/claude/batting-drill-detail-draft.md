## この資料の言葉づかい

野球経験のないコーチが読んで、そのまま使えることを優先した。

- **方向はすべて右打者を基準に書く。左打者は左右を反転する。**
- 方向は**投手方向／一塁側／三塁側**の3つだけで書く。
- **「下の手」＝グリップの下側の手**（右打者なら左手）。**「上の手」＝上側の手**（右打者なら右手）。
- 「腰」は骨盤のこと。「胸から腰までの上体」は胸郭のこと。専門語は括弧で添えるだけにする。
- **「選手に言う言葉」「コーチが見るところ」「できている形」「なぜそうなるか」は分けて書く。** 混ぜると現場で使えない。
- **「原典の説明」の引用だけは、本の言葉をそのまま残す**（「ボトムハンド＝下の手」「骨盤＝腰」「ヘッド＝バットの先」）。後で本と照らし合わせるため。**選手やコーチに渡す最終資料には、引用をそのまま載せない。**

## 1. 全体の組み立て — なぜこの5本なのか

**5本はフラットに並んでいるのではなく、下に土台があり、その上に4つが載る。**

```
                  ┌──────────────┐
                  │  基礎の体操   │  腰を止めて、上だけ回せるようにする
                  │  (p054-057)  │  ← 体重移動と割れの両方の土台
                  └──────┬───────┘
         ┌───────────────┼───────────────┐
         ▼               ▼               ▼
   ① 体重移動        ④ 割れ         ③ トップ      ② 下の手の肩のリード
   (p066-069)     (p135-139)     (p144-147)      (p072-085)
   土台の能力を     土台の能力を     踏み出しと      ここだけ実際に
   一歩の移動と     打撃に近い       グリップを       球を打つ
   着地に載せる     下半身の条件で   引く動きを      （置きティー）
                   割れとして出す   合わせる
```

**この構造は原典が自分で説明している。** p056-057 にこうある。

> それら（胸から腰までの上体・肩甲骨・背骨）が動けば、**腰も顔も動かさずに上体だけを回すことができる**のです。ですから、バッティングで「頭を動かさずに軸回転で打つ」などと言われる動作は、ステップで前に進んでから着地後、これらの関節が十分に動くことによって、**後ろ腰が前に進みながらも、その腰の動きの影響を受けずに、上体が背骨を軸に回転して両肩が入れ替わって実現している**のであり、**いくら「頭を固定しろ」と言っても、これらの関節の動きが悪ければ不可能なのです。**

つまり原典は、基礎の体操で作る能力を、**「後ろ腰が前に進む（＝体重移動）」と「上体だけが回る（＝割れ）」の両方の前提条件**として説明している。だから基礎は準備運動ではなく、土台として1本を使う。

1グループ6〜7名、コーチ2名、20分×2枠。**このモジュールを行うのは常に1グループだけ**で、他のグループは守備などの別メニュー。グループが入れ替わる。

| 枠 | 時間 | 内容 |
|---|---|---|
| 第1枠 | 0:00-5:00 | **基礎** 腰を止めて上だけ回す体操（p054-057） |
| | 5:00-10:00 | **① 体重移動** 一歩ステップと腰・上体の回転（p066-069） |
| | 10:00-14:00 | **③ トップ** トップのつくり方①（p144-147） |
| | 14:00-18:00 | **④ 割れ** 割れをつくるステップ（p135-139） |
| | 18:00-20:00 | 確認・グループ交代 |
| 第2枠 | 0:00-8:00 | **② 下の手の肩のリード** 左右対称スイング（素振り） |

**道具は1セットでよい**（ティー2台、ネット2面、プラスチックバット6〜7本）。1グループずつ回るので、置き場所は終日固定する。

# ■ 基礎 ─ 腰を止めて、上だけ回す体操

**原典**: p054-057「上体の回転動作の動きづくりの体操」
**検証**: 400dpiで本文を確認済み

## 何のためにやるか

**腰（骨盤）を正面に向けたまま、胸から上だけを回せるようにする。**

これができないと、①体重移動も④割れも作れない。逆にこれができれば、その先は自然につながる。**この5本の中で、いちばん最初に、いちばん確実にできるようにしたい動き。**

## どういう効果があるか

- 腰と上体が別々に動けるようになる（これが割れの正体）
- 打つときに頭が流れなくなる。**「頭を固定しろ」と言っても直らないものが、ここで直る**（p056-057）
- バットを速く振るための回転が、腕ではなく胴体から出るようになる

## やり方

1. 肩幅より少し広めに立ち、**腰をわずかに落とす**
2. **両手を肩に置き、両肘を胴体につける。** 両腕を胴体に密着させ、**肩を前へすぼめる**
3. **腰は正面に向けたまま**、片方の肩が**真正面のあごの下**にくるように、**胸から上だけを水平に回す**
4. 左右交互にくり返す

**進め方は3段階（原典が指定）**

| 段階 | やり方 |
|---|---|
| 1 | **1回ずつ止めながら。** どこまで回るか、どう動くかを確かめる |
| 2 | 止めずに、リズムよく |
| 3 | **全速力でくり返す** |

**腰の落とし方**：膝をあまり前に出さず、**脚のつけ根を引き込むようにして軽く沈む**。上体は立てたまま。

**腕をこの形にする理由**（原典 p054）：胴体と腕を一体にして、**胴体だけの動きで上体を回す**ため。また、**回る半径をいちばん小さくして回りやすくする**ため。

## 選手に言う言葉（1回に1つだけ）

- 「腰は正面のまま、上だけ回す」
- 「肩をあごの下まで」

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 腰が一緒に回っていないか／顔が一緒に回っていないか |
| **横** | 膝が前に出て沈んでいないか／上体が前に倒れていないか／腕が胴体から離れていないか |

## できている形

腰と顔は正面のまま、肩だけがあごの下に入ってくる。

## よくある崩れ方（原典が写真番号つきで挙げている5つ）

| | 崩れ方 | どう見えるか |
|---|---|---|
| 写真3-6 | **膝が前に出ている** | 脚のつけ根ではなく膝で沈んでいる。**原典が「非常に多い」としている** |
| 写真3-7 | **上体が前に倒れている** | つけ根の引き込みを強調しすぎた結果 |
| 写真3-8 | **腕が構えの位置から離れている** | 肘が胴体から浮く |
| 写真3-9 | **膝が動いて腰も一緒に回っている** | 下半身が止まっていない |
| 写真3-10 | **腰・上体・顔がひとかたまりで向きを変えている** | 3-9をさらに極端にした形 |
| （番号未確認） | **肩があごの前に上がってしまう** | 肩がすくむ |

**崩れる理由は「やる気」ではなく体の動き。** 原典はこう説明している。

> これは、上体の回転をつくっている**胸から腰までの上体・肩甲骨・背骨**——一つ一つが動かないことによるもの

**だから、できない選手を責めない。** ここは「今どこまで動くか」を測る枠でもある。

## 安全のために

- 反動で強くひねらせない。**回る大きさを競わせない**
- 痛みや違和感が出たら中止
- 第3段階（全速力）は、第1・第2段階の形が保てている選手だけ

## 簡単にする方法・変える方法

- **腰が一緒に回ってしまう選手**：椅子に座って行う、または膝立ちで行う（原典 p052-053 に膝立ちの形がある）
- **変形（原典 写真3-11）**：腕を左右に開いた形でも行える。ただし**胸を張るように引き分けるのではなく**、真横よりやや前を向いた向きで、肘を楽に落とす

## 原典の説明（要点）

> 肩幅より少し広めのスタンスで腰をわずかに落として立ち、両手を肩に、両肘を胴体に付け、その両腕を密着させて肩をすぼめて構えます。そして、骨盤はなるべく正面に向けたまま、一方の肩が真正面のあごの下にくるように、上体だけを水平に回転させる動きを左右交互に繰り返します（写真3-4）。最初のうちは、可動域と動き方を確認するように1回ずつ止めながら行い、次第にリズミカルにして、最後は全速力で反復します。（p054）

## 外部文献が足すもの・注意を促すもの

| 出所 | 内容 | 扱い |
|---|---|---|
| Perplexity | **「頭を完全に固定すること」を目標として誤解させない** | 原典 p056-057 と完全に一致。**むしろ原典のほうが強く否定している** |
| Perplexity | 回る大きさを競わせない | 採用 |
| Tsutsui et al. 2023（少年打者の縦断研究） | 腰と上体のずれは年齢とともに変わる。**個人差が大きい** | **角度を目標にしない根拠**。ただし**このドリルの効果を検証した研究ではない** |

- 英語圏に同じ形のドリルがあるかどうかも**確認できていない**

# ■ ① 体重移動 ─ 一歩ステップと腰・上体の回転

**原典**: p066-069「上体の回転動作と骨盤の回転動作の組み合わせの体操」
**検証**: p066の本文を400dpiで確認済み。p067-069は未検証

## 何のためにやるか

**基礎の体操で作った「腰を止めて上だけ回す」能力を、一歩の移動と着地に載せる。**

打撃で言う体重移動とは、原典では**「腰を横向きに近いまま、踏み出す足の方向へ運ぶ動き」**のこと。「後ろに乗ってから前に移す」ことではない。

## どういう効果があるか

- 後ろに体重が残ったまま腕だけで振る、がなくなる
- 頭から突っ込む、がなくなる
- 着地してから体が回る順番が身につく

## やり方

1. 肩幅くらいに立つ。**腰はほとんど沈めない**
2. 顔だけ投手方向へ向ける
3. **真横にただ一歩踏み出す**
4. その一歩に合わせて、**下の手（右打者なら左手）の肩をあごの下へ引き寄せる**
5. **左足が着いた瞬間に**、腰を横向きのまま左足の方向へ運びながら回し、**同時に両肩を一瞬で入れ替える**

**バットは持たない。全員同時にできる。**

## 選手に言う言葉（1回に1つだけ）

- 「左足を静かに置く」
- 「頭だけ先に行かない」
- 「左足が着いたら、その場で回る」

## 言ってはいけない言葉

「体重を全部前へ乗せろ」／「強く踏み込め」／「腰を先に切れ」／「前の脚を伸ばして固めろ」／**「後ろに乗れ」**

> **「後ろに乗れ」がなぜ駄目か**：原典 p132 は、**軸足に体重を残してしまうことを、この年代で最も多い勘違い**として名指ししている。「後ろに乗れ」と言うと、そのまま後ろに残る。**見るのは「後ろに乗れているか」ではなく「後ろに残っていないか」。**

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 頭と胸が左足より先に大きく倒れ込んでいないか／左膝が内側へ崩れていないか |
| **横（三塁側）** | **右腰が右足の側に置き去りになっていないか**（最重要）／左足が跳ねず毎回近い位置に静かに着くか／左足がつま先だけで不安定になっていないか／左脚を早く固めていないか |

## できている形

**「左足の上で一瞬止まれて、そのあと回れる」。** 左足に飛び込むのではない。腰は横向きのまま前へ運ばれ、両肩が入れ替わっている。

## よくある崩れ方

1. **軸足に体重が残って腰が前へ進まない**（原典が最多とする）
2. 頭が横に流れる
3. 着地で左膝が内側に入る
4. 大きく跳ねる
5. 前に傾いたまま準備に入る

## 安全のために

一歩の幅を大きくさせない。バットを持たせない。前後左右の間隔は、実際に動かせてから決める（「2m」は目安であって安全の保証ではない）。

## 簡単にする方法

一歩置いたところで**一度止める**。着地の形だけ確かめる。

## 原典の説明（要点）

> まず、肩幅程度のスタンスで重心はほとんど沈めずに立ち、上体は……2つの体勢どちらかで構え、顔だけを投手方向に向けておきます。そこから、**真横にただ一歩踏み出すだけのステップに合わせて、ボトムハンドの肩をあごの下に引き寄せ**、**着地した瞬間に、下半身では骨盤を横向きに近い状態のまま踏み出し脚方向に移動させる「スライド動作」から始まる回転動作**を、上半身では**両肩を一瞬で入れ替える回転動作**を、同時に行います。（p066）

## 外部文献が足すもの・注意を促すもの

| 出所 | 内容 | 扱い |
|---|---|---|
| Driveline「Step Backs」 | 大きく跳ねる／後ろへ動かない／早く前へ出る／前に傾いたまま準備する、を誤りとして挙げている | **崩れ方④⑤として採用。** ただしこれは成人・大学選手向けの動画で、少年への効果を示すものではない |
| Perplexity | 「左足を静かに置く」「頭だけ先に行かない」など、少年向けの短い言い方 | 採用 |

- 「後ろの脚のつけ根に乗る」を10〜12歳に指示すべきかどうかは**未検証**（本案では指示にしない）

# ■ ② 下の手の肩によるスイングの始動 ─ 左右対称スイング＋置きティー

**原典**: p072-085
**検証**: p072の本文を400dpiで確認済み。p073-085は一部未検証

## 何のためにやるか

**バットを、腕ではなく「下の手の肩」から動かし始める。** そして**バットが通る面**を作る。

原典の考え方の中心はここにある。「上の手（右打者なら右手）に意識を持たせるのはマイナスにしかならない」（p018）としている。

## どういう効果があるか

- 手だけでバットを放り出す（腕が先に体から離れる）がなくなる
- バットが遠回りしなくなる
- 手首を返そうとしなくなる（返そうとしなくても返る）

## やり方

1. **立てたバットの真上に頭がくるように立つ**
2. 踏み出す脚が前。**その脚に全体重を乗せる。** 後ろの脚はバランスのため、つま先を床に触れさせておくだけ
3. **下の手1本**でバットを握る
4. バットを立てていた位置（頭の真下）を中心に、**振り子のように左右へ揺らす**
5. **バットの先の動きが、つま先の向いている正面方向に対して、きっちり直角になるようにする**
6. そこから実際に振る

**段階（同じ日の中で使い分ける。日ごとの進級ではない）**

| 段階 | 内容 |
|---|---|
| 1 | 片手・真下 |
| 2 | 両手・真下 |
| 3 | 両手・ベルトの高さ |

**崩れたら、その場で段階を下げる。**

**使うバット**：原典は年代別に指定している。**小学生はプラスチックバット。** 中学生は小学校低学年用バット、高校生はノックバットを短く持つ。一度できるようになれば通常のバットでよい。

## 置きティー（1人5球×1巡）

- **打ちごろの位置に置かない。** 作ったスイングが**そのまま出せる位置**に置く（p085）
- **高めから始めて、できるようになったら次第に低くする**（p106）
- **ストライクゾーンを打つ練習ではない。** 原典は「ストライクゾーンの球を打つことにこだわっていては何も変わらない」としている（p082）

## 選手に言う言葉（1回に1つだけ）

- 「肩から先に動かす」
- 「手だけでバットを放り出さない」
- 「返そうとしない。勝手に返る」

## 言ってはいけない言葉

「前の肩を強く引け」／「上の手で押し込め」（原典 p018）／「手首を返せ」／「フォロースルーを大きく」（原典 p092：原因が変わらなければ大きくならない）

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面または真後ろ** | 左右対称に振れているか（**一目で分かる**）／打つときに顔が早く三塁側を向いてボールから目が切れていないか |
| **横** | 下の手の肩→腕→バットが一直線になり、地面と平行になっているか（p075）／腕とバットだけが先に体から離れていないか |

## できている形

軌道が左右対称。肩→腕→バットのラインが地面と平行。

## よくある崩れ方

1. 手だけでバットを放り出す
2. 上の手が働きすぎてバットが遠回りする
3. 手首を早く返して上からかぶせる
4. 両手にした途端に崩れる
5. 打ちごろの高さばかり打とうとする

## 安全のために

- **素振りの間隔は、実際にバットを振らせて重ならないことを確かめてから決める**
- **バットを持つ選手と持たない選手の場所を分ける**
- ティー係は**バットが完全に止まってから**入る
- 待つ列に安全線を引く

# ■ ③ トップの作り方 ─ トップのつくり方①

**原典**: p144-147
**検証**: p145の本文を400dpiで確認済み。p146-147は一部未検証

## 何のためにやるか

**踏み出しとグリップを引く動きの、タイミングを合わせる。**

原典は3通りの方法を示しているが、これを**「最も単純で誰でも簡単に行える方法」「一からスイング動作を正しくしていく場合によく用いている」**としている（p145）。**5本の中で唯一、原典が「誰でもできる」と明記しているドリル。**

## どういう効果があるか

- 手だけを後ろに引く、がなくなる
- **形を指示しなくてもトップが決まる。** 肩に担いだ構えでは、バットの先は自然に頭の後ろ、上の手の肘は自然に下向きになる

## やり方

1. **バットを横に寝かせて肩に乗せる**
2. 肩幅くらいの**狭いスタンス**でリラックスして立つ
3. **一歩の踏み出しに合わせて、下の手の動きでグリップを引く**

**これだけ。**

**構えは直しに行かない。** 原典は「構えの方法は自由」「すり足でも一本足でもどちらでも構わない」としている。

## 選手に言う言葉（1回に1つだけ）

- 「足といっしょにグリップが離れる」
- 「手だけを後ろへ引かない」

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **横** | バットの先やグリップが投手方向へ入りすぎていないか／グリップが背中側へ深く入りすぎていないか |
| **正面** | 腰が投手に対して真横のまま前へ進んでいるか |

## できている形

**グリップは前後に動くが、腰は真横のまま前へ進む**（p146）。

## よくある崩れ方 ─ 原因が逆なので、見分けてから声をかける

| 見え方 | 原因 | かける言葉 |
|---|---|---|
| **投手方向へ入りすぎ** | **上の手が働きすぎている** | 「手だけを後ろへ引かない」 |
| **背中側へ深く入る** | **腰ごと上体が回ってしまっている** | 「腰は正面を向いたまま」 |

**同じように見えて処方が逆。** ここを間違えると悪化する。

## 安全のために

間隔をとる。バットを肩から外すときに後ろを確認させる。

## 簡単にする方法

**区切り動作**：踏み出したところで一度止める。→ 慣れたら連続。

## 原典の説明（要点）

# ■ ④ 割れ ─ 割れをつくるステップ

**原典**: p135-139（量の上限は p038、タイミングは p137、変形は p140-141）
**検証**: p135の本文を400dpiで確認済み。p136-139は一部未検証

> **このドリルの扱いは、まだ決まっていない。**
> 原典はこのドリルを**「特に、着地時にどうしても踏み出し脚の膝が内に向いてしまって、上半身との間に十分な割れをつくれない選手のためのドリル」**と、対象を限定して紹介している（p135）。他の4本には限定がない。
> **全員が毎回やる定番として使う場合は、「原典では対象を限定したドリルである」ことを資料に明記する必要がある。** Codexはこの点を理由に定番から外すべきという立場。§9の未決事項1。

## 「割れ」とは何か

原典の定義は **「下の手の側の肩が、少し引っぱられている状態」**（p084）。角度でも、大きさでもない。

## 何のためにやるか

**このドリルで全員に教えたいのは、角度ではなく時間。**

> **左足が着く寸前までに、グリップを引く動きが終わっている**（p137）

基礎の体操で作った「腰を止めて上だけ回す」能力を、**打撃に近い下半身の条件の中で出す**。

## どういう効果があるか

- 着地してからグリップを引き始める、がなくなる
- 腰だけが早く開く、がなくなる
- 踏み出す足の膝が内側に入る選手に、特に効く

## やり方

1. **両足をつけて立ち、脚のつけ根を後ろに引き込みながら軽く膝を曲げて構える**
2. **両膝だけを、投球が来る方向へ向きを変える**
3. その膝の向きを固定しておくつもりで、**上半身を、膝と逆の45度方向へわずかにかぶせる**
4. そこから一歩踏み出し、**着地で割れをつくる**

**前半はバットなし。後半だけバットを持つ。**

## 量の上限（守る）

> 上体は本来あまり深く捻らなくてよい。**下の手側の肩を引き寄せるくらい**の方が効果的（原典 p038）

**大きくする方向へ持っていかない。選手どうしで大きさを比べさせない。**

## 選手に言う言葉（1回に1つだけ）

- 「左足が着く前に、グリップを引こう」
- 「左足が着いたら、引くのはおしまい」

## 言ってはいけない言葉

「胸を強くねじれ」／「腰を開いてから上体を回せ」／**「割れを大きく」**／「上体を大きく三塁側へ向けろ」

## コーチが立つ場所と見るところ

| 立つ場所 | 見るところ |
|---|---|
| **正面** | 腰や膝まで一緒に動いていないか／左足が着くときに胸と両肩が投手方向へ開き切っていないか |
| **横** | 左足が着く寸前にグリップを引き終わっているか／**腰が反っていないか**／上体が前に折れていないか |

## できている形

左足が着いた瞬間に、グリップの動きがすでに止まっている。腰は反っても折れてもいない。

## よくある崩れ方

1. 膝と一緒に腰まで回る
2. **腰が反る**
3. 肩がすくむ
4. グリップを引き終わるのが着地より遅れる
5. 大きくしようとしてねじる

## 安全のために

- **腰が反ったら、その場で止めて、バットなしの形の確認に戻す**
- 動きの大きさ、着地の幅を競わせない
- 痛みや違和感が出たら中止
- 土日連続で行うので、回数を増やさない

## 簡単にする方法・変える方法

- **簡単形**：バットなしで形の確認だけ
- **膝の向きが崩れる選手**：つま先の向きを変えた形（原典 p140-141）。**これは発展形ではなく、膝の向きを直すための修正**

## 原典の説明（要点）

> これは、**特に、着地時にどうしても踏み出し脚の膝が内に向いてしまって**、上半身との間に十分な「割れ」をつくれない選手のためのドリルです。両足を付けたスタンスで、両股関節を後ろに引き込みながら軽く膝を曲げて構えます。（p135）

## 外部文献が足すもの・注意を促すもの

| 出所 | 内容 | 扱い |
|---|---|---|
| Perplexity | **角度の最大化を狙わない。** 姿勢、荷重、静かな着地、上体から肩・腕・バットへのつながりを優先 | **全面採用。** 原典 p038 の上限と一致 |
| Perplexity | 腰の反り、頭の流れ、肩のすくみ、腕の遅れすぎを避ける | **安全欄に採用** |
| Driveline「5 Hitting Drills」3:17〜4:18 | 腰を反りすぎると回転が妨げられる | 姿勢の観察のみ参考 |
| Tsutsui et al. 2023 | 腰と上体のずれは発達途上で個人差が大きい | **角度を求めない根拠。ただしこのドリルの効果を検証した研究ではない** |

## 外部文献では確認できないこと

- **10〜12歳全員に割れの専用ドリルを毎回行うことの是非を検証した研究は確認できていない**

- 疲れて形が崩れてきた

1. 一つの団体が公開している ← **今回参照した外部資料はすべてここ〜3の段階**
2. 同じ団体の複数の動画に出てくる
3. 同じ系列で複数回使われている

5. 少年向けの公式指導資料に載っている
6. 研究でそのドリルの効果が直接検証されている

**したがって「広く採用されている」「少年に有効である」とは書かない。**
