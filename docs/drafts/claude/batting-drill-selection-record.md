## 3. 要素に分解して照合し、厳選する

**ドリルの名前を突き合わせても意味がない。** 原典は40近いドリルを写真と手順と狙いつきで載せている。**その動作要素を、成人向け指導・バイオメカニクス・医学・少年向けの注意と照合して、どれが最適かを決める。**

### 3-1 外部資料が実際に語っている9つの要素

外部資料が「何かを言っている」動作要素は、次の9つに整理できる。**この9つが照合の物差しになる。**

| | 要素 | 外部資料が言っていること |
|---|---|---|
| **A** | **踏み出し足の接地**（安定・再現性） | 接地が連鎖の節目（Welch）／踏み出し脚側の水平の地面反力が体幹のエネルギーの流れと関係する（Horiuchi）／**痛みを伴う反復着地・不安定な着地・膝の内側崩れを続けない**（医学）／短く柔らかい踏み出し（Cal Ripken）／**大きく跳ねる・早く前へ出るは失敗例**（Step Backs） |
| **B** | **腰が軸足側に残り切らない／頭・上体だけ突っ込まない** | 後方への準備→接地→腰・上体・腕の連鎖（Welch）／**少年と成人では踏み出し脚の動きも腰・上体の向きも違う**（Escamilla）／**前の脚の強い固定・大きな後ろ乗りは持ち込まない** |
| **C** | **腰と上体の時間差を、角度ではなく時間で扱う** | **年齢で相対的なずれが変わる＝角度を求めない**（Tsutsui）／分離は強い逆ひねりでなく制約で作る（Driveline）／**腰の反り・回しすぎ・横崩れの代償を反復させない。若年の腰椎分離症**（医学） |
| **D** | **上体そのものの回旋（胸から腰までの上体・肩甲骨・背骨）** | 腰→上体→腕→バットの順に速さが乗る（運動連鎖）。**ただし「これだけを単体で鍛えるドリル」は外部資料に見当たらない。** 逆に**「腰を完全固定して上体だけを強く回す」は代償が集中する**と医学側が警告 |
| **E** | **上体→肩→腕→バットの連続（手・腕だけ先行させない）** | **振り始めに手が体から早く離れるのを抑える**（MLB Connection Ball）／腕も連続動作に含まれる（Welch）／**肩だけを強く引く・出すは首・肩まわり・腰の代償**（医学） |
| **F** | **バットの通り道（面・方向・高さ）** | バットの深さ・方向性・上からかぶせる動きを見る（Offset Open）／ティーでバットの通り道を確認する（Little League） |
| **G** | **準備（グリップを引く動き）と踏み出しの時間関係** | ロードとストライドのタイミング（Driveline／Little League）／**グリップを背中側へ引き続けると肩・首が張る。着地後も手だけで引き続けるのは遅れ**（医学） |
| **H** | **姿勢の維持（脚のつけ根で支える・腰を反らない）** | 姿勢は腰の反りや曲げで作らず**股関節で支える**（Driveline hip hinge／spine angle）／腰椎の代償を避ける（医学） |
| **I** | **置きティーから、投げられた球への転移** | **ティーと投げられた球では上体の動きが同じにならない**（Bordelon） |

**要素になっていないもの**：割れの角度、後ろに乗せる割合、回転の速さ、バットの速さ——**外部資料はどれも「少年に目標として与えるな」と言っている側**。だから照合の物差しにしない。

### 3-3 要素ごとに、何が最適か

**選ぶ基準**（2026-09-12 改訂）

1. **その要素が主目的になっているか**
2. **ドリルとして汎用的か**（限定的な崩れにしか効かない手段を使っていないか）
3. **指導者が、原典の写真と文章から、正しい動作を読み取れるか** ← **追加**
4. **選手が、正しい動作を自分で実感できるか** ← **追加**
5. **少年に持ち込めない要素**（角度目標・強い固定・重い道具・速さ比べ）**を含まないか**
6. **この資料だけを読んで、正しい動作を教えられるか** ← **最重要（2026-09-12 追加）**

> **【訂正】** 前版は「6〜7名が同時にできるか」「道具が少ないか」を選定基準に入れていた。**これは運用の話であって、ドリルの良し悪しではない。** 参考情報としては残すが、**採否の基準から外す。**

> **【追加 2026-09-12】3と4は、実は最も重いかもしれない。**
> 教えるのは**野球経験のないお父さんコーチが大半**である。**原典の写真を見て、文章を読んで、正しい動作が分からないドリルは、どれだけ理屈が正しくても現場で機能しない。**
> 同じく、**選手が「できた／できていない」を自分で感じられないドリル**は、コーチが毎回口で言い続けるしかなくなる。

#### p122-127 から①へ持ち込むもの

**この体操は、①p066-069 が使っている「スライド動作」を、2段階に分けて取り出したもの。** 以下は**①の観察点と言葉として取り込む。**

> **【訂正 2026-09-12】道具の記述が誤っていた。**
> 前版は「水平な棒・柵に手をついて行う」と書いていたが、**正しくは椅子。** 写真5-6・5-7 で、選手は**椅子の背を両手で支えて**いる。低解像度の切り出しを読み違えていた。
> **椅子1脚でできる。** 「器具が要るから候補から外す」という前版の判断は、**前提が誤っていた。**

**(1) 軸足の返り方が、腰の動きを映す鏡になる** ← **未経験コーチ向けに最も価値がある**

> まず横向きに返って**親指の内側で地面を支えた状態**を経由します。それは、骨盤の回転動作の動きが横移動を含んで**後ろ腰が直進している**ことの何よりの証拠です。**軸足は骨盤の動きに引っ張られて返るものなので、その返り方は、骨盤の動きを映す鏡なのです。**（p124）

**腰の中は見えないが、足は見える。** 軸足がどう返るかを見れば、腰が直進したかどうかが分かる。**①のコーチBの観察点に追加。**

**(2) 「ステイバックライン」＝目で見て確認できる形**

> **踏み出し脚の足元から頭までの斜めの一直線**になった、**「ステイバックライン」**と呼ばれる体勢（写真5-2C、5-3C）（p123）

スライド動作で骨盤が踏み出し脚へ進まないと、この形はできない。**①の「できている形」に追加。**

**(3) スライド動作が無いとどうなるか**

> この骨盤の「スライド動作」がなく、いきなり回転動作を働かせた場合……**「スライド動作」がなければ、骨盤は逆回りにしか回転することができません**（p123）

**「腰だけ先に回す」が、なぜ駄目なのかの答え。** ①の「言ってはいけない言葉」の理由として使う。

**(4) 「壁」の正体**

> 後ろ腰は直線的に前に進むことができ、**回転の支点を踏み出し脚に移してこそ回ることもできる**のです。そうして得られる感覚は**「壁」**と呼ばれ……（p123）

**現場で使われる「壁を作れ」は、これのこと。** ただし「壁を作れ」とだけ言っても何をすればよいか伝わらないので、**声かけには使わない。コーチが理解するための言葉として用語集に入れた。**

**③ D（上体回旋を単体で鍛える）は、外部資料に裏づけが無いどころか、注意の対象**

外部資料に「上体の回旋だけを単体で鍛えるドリル」は見当たらない。**逆に医学側は「腰を完全固定して上体だけを強く回す」を代償の集中として警告している。**

**それでも p054-057 を残すのは、①原典が土台と位置づけている ②崩れ方を写真つきで5つ明示していて、コーチが見て判断できる材料が最も多い、から。** ただし外部の警告に合わせて条件をつける。

- **「腰を止める」は体操の中だけの決まりごと。打つときに腰を止めるという意味ではない**（原典 p188 も同じ）
- **「強くひねる」のではない**
- **第3段階（全速力）は全員必須にしない。** 第1・第2段階の形が保てている選手だけ
