# 打撃用語集 — 知っておく言葉と、練習で使う言葉

**作成**: 2026-09-10 JST
**目的**: コーチが資料を読むときに困らないよう、専門用語の意味を残す。ただし**練習で選手に言う言葉は、右列に置き換える**。
**方針**: 野球経験のないコーチも指導する前提。左列は「知っておく用」、右列は「口に出す用」。

---

## 0. 方向の書き方（全資料共通）

- 方向はすべて**右打者を基準**に書く。**左打者は左右を反転する。**
- 使う言葉は**投手方向／一塁側／三塁側**の3つ。
- **「ネットを向く」「胸をネットへ回す」は使わない。** 打席の向きを誤認させる。
- 右打者の場合の対応
  - 踏み出す足＝**左足**／軸になる足＝**右足**
  - 下の手（ボトムハンド）＝**左手**／上の手（トップハンド）＝**右手**
  - 打ち終わりに上体が向くのは**三塁側**
- **実打撃へ持ち込む共通の3語**（右打者）
  > **「左足を置く。胸を急がない。体ごと三塁側へ回る。」**
  この順序は、動作の時間が完全に分かれていることを教えるものではない。**覚えやすくするための簡略化**である。

## 1. 原典が使っている言葉

| 用語 | 何を指すか | 練習で使う言葉 |
|---|---|---|
| **ボトムハンド** | グリップの下側の手。右打ちなら左手、左打ちなら右手 | 「下の手」「左手（右打ちの場合）」 |
| **トップハンド** | グリップの上側の手。右打ちなら右手 | 「上の手」 |
| **トップ** | 振り出す直前の準備の体勢 | 「振り出す前の形」 |
| **割れ** | ボトムハンド側の肩にストレッチがかかった状態（原典 p084 の定義） | 「下の手の肩が、少し引っぱられている感じ」 |
| **捻れ** | 骨盤と上体の向きのズレ（原典 p028） | 「腰と胸の向きが少しずれている」 |
| **テイクバック** | トップへ向かってグリップを引く動き | 「グリップを引く動き」 |
| **スイングプレーン** | バットが通る面（球に向かう角度） | 「バットが通る面」 |
| **胸郭** | 胸から腰までの上体の骨格 | 「胸から腰までの上体」 |
| **肩甲骨の外転** | 肩甲骨が背中から前方向へ動くこと（肩がすぼむ方向） | 「肩を前へすぼめる」 |
| **基本姿勢** | 踏み出し脚に全体重を乗せ、投手方向に正対した姿勢（原典 p022） | 原典の言葉のまま使ってよい |
| **スライド動作** | 骨盤が横向きのまま踏み出し脚方向へ移動すること（原典 p066） | 「腰が横向きのまま前へ運ばれる」 |

### 原典が言葉の意味を作り替えているもの

| 用語 | 世間の意味 | 原典の意味 | 練習で使う言葉 |
|---|---|---|---|
| **ダウンスイング** | 上から叩く | **振り出しからインパクトまで、グリップの動きが上から下へ向かうこと**（p088-089） | 「グリップから先に出す」。「上から叩け」は使わない |
| **アッパースイング** | 下から上へ振る | **グリップよりヘッドが低く、トップハンド主体でバットが遠回りに出ること**（p089） | 「バットが遠回りに出ている」 |
| **開かない** | 我慢して開かないこと | **腰が横向きのまま前へ進むことと、両肩を素早く入れ替えることが両立した結果**（p190） | 「開くな」は使わない。「後ろの腰をまっすぐ前へ」＋「肩を素早く入れ替える」に分ける |

## 2. 英語圏の指導で定着している言葉

原典には出てこないが、Driveline等の資料を読むときに出てくる。**練習では使わない。**

| 用語 | 何を指すか | 練習で使う言葉 |
|---|---|---|
| **load（ロード）** | 振り出す前に後ろ側へ体重を乗せて準備すること | 「後ろのお尻に乗る」 |
| **coil（コイル）** | 骨盤と体幹がねじれを蓄えること | 「腰と胸の向きが少しずれる」 |
| **casting（キャスティング）** | 振り出しで手・腕・バットだけが身体から早く離れること | 「手だけでバットを放り出している」 |
| **hinge（ヒンジ）** | 股関節から折れて前傾する姿勢 | 「股関節から軽く曲げた前傾」 |
| **hip-shoulder separation** | 骨盤と肩の向きの差 | 原典の「割れ」に当たる。**分離を大きくすることは目標にしない** |
| **spin out（スピンアウト）** | 回りすぎて軸が流れること | 「回りすぎて崩れている」 |
| **rollover（ロールオーバー）** | 手首が早く返って上から被せてしまうこと | 「手首が早く返っている」 |
| **stride（ストライド）** | 踏み出し | 「踏み出し」 |

## 3. 研究・科学の言葉

資料の根拠を読むときに出てくる。**練習では使わない。**

| 用語 | 何を指すか | 練習で使う言葉 |
|---|---|---|
| **地面反力** | 足で地面を押したときに地面から返ってくる力 | 「地球からパワーをもらえぇ〜」（チームの既存語彙。既に通じており、身体ではなく外を指している） |
| **運動連鎖** | 身体の部分が順に動いて力がバットへ伝わるつながり | 「下から順につながる」 |
| **慣性モーメント（MOI）** | バットの振りにくさ。重さそのものではなく、重さの位置で決まる | 「振りやすさ」。**「重い／軽い」ではなく「振れるか」で選ぶ** |
| **外的焦点** | 身体ではなく、ボールやバットの先など外側を指す言い方のほうが習得が早い、という考え方 | 用語としては使わない。**言い方の指針としてだけ使う** |
| **overuse（オーバーユース）** | 同じ動作の繰り返しによる故障 | 「使いすぎのケガ」 |

### 子どもに位置を伝えるための目印

| 言葉 | 何を指すか | 注意 |
|---|---|---|
| **「おへそ」** | 腰まわりの骨（骨盤）の位置を、子どもに分かりやすく伝えるための目印 | **厳密な用語ではない。** 「おへそを少し前へ運ぶ」のように、動く向きを示すためだけに使う。おへその角度を測ったり、目標にしたりしない |
| **「あごの下」** | 肩が収まる位置の目印（原典 p066、p175 が使っている） | 「肩をあごの下へ入れろ」は**最初の主な指示にしない**（§4）。準備運動での目標としてだけ使う |

## 4. 使ってはいけない言葉

| 言葉 | 理由 |
|---|---|
| **「キュー」** | 意味が伝わらない。「選手への声かけ」「その場で伝える言葉」と書く |
| **「ネットを向く」「胸をネットへ回す」** | 打席の方向を誤認させる。**投手方向／一塁側／三塁側**で書く（右打者基準。左打者は左右を反転） |
| **「ロードポジション」** | 原典にない語。日本の少年野球でも定着していない |
| **「トップハンドで押し込め」** | 原典は「トップハンドに意識を持たせるのはマイナスにしかならない」としている（p018） |
| **「フォロースルーを大きく」** | 根本原因が変わらなければ大きくならない（p092） |
| **「手首を返せ」** | 手首は自然に返る。返るのは肩の向きが変わり続けるから（p076, p178） |
| **「割れを大きく」** | 原典は「上体は深く捻らなくてよい。ボトムハンド側の肩を引き寄せるくらい」としている（p038） |

### 体重移動で言わない言葉

| 言葉 | 生みうる誤り |
|---|---|
| **「体重を全部前へ乗せろ」** | 前への突っ込み、頭が先に出る |
| **「強く踏み込め」** | 前への突っ込み、着地が暴れる |
| **「左足を軸として身体を固定しろ」** | 前脚の硬直、回転が止まる |
| **「前脚を最初から伸ばして固めろ」** | 前膝の硬直 |
| **「腰を先に切れ」** | 腰だけの早開き |
| **「後ろに乗れ」** | **軸脚に体重が残る。原典 p132 がこの年代で最も多い誤認識として名指ししている** |
| **「腰は前、頭は後ろ」** | 頭を意図的に後ろへ傾ける誤解。→ **「頭だけ先に行かない」**と言う |

### 上体の回転で言わない言葉

| 言葉 | 生みうる誤り |
|---|---|
| **「前肩を強く引け」** | 肩だけの回転、腕だけの操作 |
| **「右肩を前に突っ込め」** | 肩が落ちる、前へ突っ込む |
| **「胸を強くねじれ」** | 腰の反り、肩のすくみ、腕の遅れすぎ |
| **「腰を開いてから上体を回せ」** | 早開き |
| **「頭を動かすな」** | 回転が途中で止まる、視線が固まる |
| **「上体を大きく三塁側へ向けろ」** | 回りすぎて崩れる |
| **「右肩を顎の下へ入れろ」** | 右肩が落ちる、首が傾く、腰が反る、顔が早く切れる。→ **「右肩は、体の回転についてくる」**と言う。あごの下に収まるかどうかは**コーチが見る目安**であって、選手への指示ではない |

## 5. 書き分けのルール

資料を書くときは、次の6つを混ぜない。

1. **選手に直接言う言葉**
2. **コーチが見るための確認項目**
3. **できたかどうかを判断する最終的な見え方**
4. **専門的な補足説明**
5. **外部資料が直接確認している事実**
6. **今回の少年向けの翻訳・簡略化の提案**
